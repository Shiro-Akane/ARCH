# CooperativeHotspots 首轮筛选

## 目的

本案例检验两个单独热点是否能通过反应波和压缩波相互作用，产生超过单热点与等总热量单连通热点的协同增益。首轮只作机制发现，不给出天体物理临界半径或最终核合成结论。

四种几何由 `hotspot_mode` 选择：

- `single`：一个半径为 `R` 的圆；
- `double`：两个半径为 `R`、中心距为 `d` 的不重叠圆；
- `equal_energy`：一个半径为 `sqrt(2) R` 的圆，连续极限下面积与双圆相同；
- `elongated`：半轴为 `2R` 和 `R` 的椭圆，连续极限下面积也与双圆相同。

热点与环境具有相同组分，热点密度由 Helmholtz EOS 的对数密度二分求解，使初始压力严格相等。首轮公共设置为二维 Cartesian、`dx=1 cm`、HLLC、MUSCL-MC、RK2、Helmholtz EOS、`aprox13`、ROS4、无 AMR、无重力、无扩散和无 NSE。环境为

```text
rho_ambient = 4.0e7 g cm^-3
T_ambient   = 2.0e8 K
X(He4)      = 0.8
X(C12)      = 0.2
R           = 6 cm
```

等压求解在 `T_hot=4.0e9 K` 时得到 `rho_hot=2.03185e7 g cm^-3`，相对压力差为 `2.43e-15`；在 `T_hot=3.5e9 K` 时得到 `rho_hot=2.33353e7 g cm^-3`，相对压力差为 `3.65e-15`。

`d=14 cm` 的双热点有小幅反应增益，但小于等总能量单圆；`d=12 cm` 没有继续增强。该层不满足协同机制的必要对照。

关闭核反应后，`d=14 cm` 双热点在 4.1 ns 的压力相对起伏约 `1.5e-13`，速度不超过 `4.4e-6 cm s^-1`，温度保持初值到约 `1e-12` 的相对精度。因而上述小增益不是初始压力不平衡或接触面数值波造成的。

双圆相对单圆的峰放能率高 `2.36%`，但等总能量单圆相对双圆又高 `2.12%`；等总能量单圆的峰温、峰压、He 消耗和单位初始热区面积放能也全部更强。该层同样不满足 `D 成功、S 与 E 失败`，当前差异更符合总热量和连通热区尺度控制。

## 首轮判定

当前结果是 **HOLD，而不是 GO**：尚无证据支持 cooperative hotspot ignition 是独立于总热量或总热体积的新机制，不应立即扩展为大参数研究。它也不是严格的最终 NO-GO，因为本轮尚未先通过半径扫描找到“单热点已经确认熄灭”的 `R < Rcrit` 窗口，且 top-hat 温度核、`aprox13` 和当前分辨率只适合作发现筛选。

只建议再设置一道廉价止损门：

1. 用单热点半径二分找到在统一终止判据下确认熄灭的 `Rcrit`，取 `R/Rcrit = 0.7, 0.85`；
2. 对每个 `R` 只扫三到四个 `d/(cs tau_ind)`，并同时运行 `S/D/E`；
3. 用亚声速衰减、持续爆轰速度、反应区与冲击锁定、域外传播距离共同定义成功/失败，不能只用峰温；
4. 对唯一最强候选做 `dx/2` 和 `aprox19` 复核；
5. 若 `D` 仍不超过 `E`，立即停止该 topic，把计算资源转到 stage-resolved cellular propagation/composition closure。

默认的参数文件已恢复为 4.0 GK 单热点的快速运行模式。若需复现上述各个测试层，请直接修改 `hotspot_mode`、`hotspot_separation`、`hotspot_temperature`、`tmax` 以及 `base_name` 等参数即可。
