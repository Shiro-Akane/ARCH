# Helmholtz runtime table

[helm_table.dat](helm_table.dat) is the Timmes Helmholtz table consumed by the
production EOS. Git LFS stores the table; a usable checkout needs the actual
data rather than only its LFS pointer.

For detailed runtime path configuration, please consult the [EOS table guide](../../README.md). Canonical source records, integrity metrics, and author-contact information are maintained in [THIRD_PARTY_NOTICES.md](../../../THIRD_PARTY_NOTICES.md). You must keep those records unified rather than carelessly duplicating checksums or attempting to alter the tabular data here.

Scientific checks are described in [EOS validation](../../../validation/eos/README.md)
and [burn validation](../../../validation/burn/README.md).
