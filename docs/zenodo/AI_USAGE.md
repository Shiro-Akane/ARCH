# AI 使用说明 / AI-use disclosure

AI 辅助用于 bug 追踪与修复、CTest 容差设置核对、代码补全、部分文档编辑，以及工程和安全检查。Windows 原生适配中也用于平台实现、失败诊断、回归和依赖审阅；DeepSeek 提供独立复核。

软件整体架构由人类贡献者设计与搭建。科学定义、数值验收标准、代码审查及发布决定由人类维护者负责。AI 工具不列为软件作者，作者及贡献见[贡献说明](CONTRIBUTIONS.md)。

AI-assisted tools were used for bug tracking and fixes, review of CTest tolerance settings, code completion, selected documentation editing, and engineering and security checks. Native Windows work also used assistance for platform implementation, failure diagnosis, regressions and dependency review, with independent reviews from DeepSeek.

Human contributors designed and built the overall software architecture. Human maintainers are responsible for scientific definitions, numerical acceptance criteria, code review and release decisions. The [contribution statement](CONTRIBUTIONS.md) identifies the software authors.
