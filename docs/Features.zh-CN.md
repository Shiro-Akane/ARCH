# ARCH 功能清单

[English](Features.md) · [算例指南](guides/SimulationCase.zh-CN.md) · [参数与接口参考](Reference.zh-CN.md) · [验证范围](../validation/README.zh-CN.md)

本页用于选择算例所需的能力。表中列的是现行实现；具体参数、可组合条件和科学验收范围分别见参考手册与验证记录。输入、输出和物理常数统一使用 CGS。

| 功能 | 现行能力 | 使用时核对 |
| --- | --- | --- |
| 流体 | 一至三维可压缩有限体积流体；SW、VL、Roe、HLL、HLLC 通量；PCM、MUSCL/PLM、PPM 重构；Euler、SSPRK2、SSPRK3 时间推进 | 通量与 EOS 的适配、粗细网格面的重构、耦合问题的时间精度 |
| 网格与边界 | 笛卡尔、柱坐标和球坐标块网格；周期、流出、反射、指定入流与用户物理边界 | 二维柱坐标采用轴对称 `(r,z)`；二维球坐标采用赤道极坐标 `(r,phi)`；三维柱坐标为 `(r,z,phi)` |
| 自适应网格 | 动态细化／粗化、守恒状态迁移、跨块交换和流体／扩散通量修正 | 细化指标与具体物理场的适用性 |
| 状态方程 | 理想气体、Helmholtz、规范化三／四维自由能表、受支持的原生 EOSDriver 与重子表 | 表格的物理分量声明、有效域和温度反解 |
| 扩散 | 热、黏性和组分通道；RKL1、RKL2 推进 | 系数来自所选材料模型；Helmholtz 恒星输运分支提供热传导 |
| 核反应 | iso7、aprox13、aprox19、aprox21；符合接口的生成网络；BE_NR、ROS4、BD 积分；具备模型资格时使用 NSE | 生成网络的设备数学能力、网络与 EOS 的相容性 |
| 线性求解 | 小型燃烧 ODE 使用 DenseLU；大型稀疏燃烧系统在 CPU 上可用 KLU、在 CUDA 上可用 cuDSS；自引力使用复合多重网格 | cuDSS 为可选依赖；燃烧与泊松求解器各自负责不同方程 |
| 重力 | 外部加速度与随流体状态更新的自引力势、加速度和能量功 | 自引力域与边界的具体条件见下表 |
| 执行后端 | CPU/OpenMP 与 CUDA 共用物理和数学实现；动态 AMR 在主机管理拓扑、设备执行数值任务 | 构建与网络能力决定可选后端；实际加速取决于算例规模 |
| 输出与恢复 | HDF5 流体场、检查点、求解与修复诊断；相容配置可在 CPU/CUDA 之间续算 | 恢复时须保持 EOS、网络、几何、引力与控制参数的科学身份 |
| Studio（选配） | Linux／WSLg 独立窗口；配置、构建、运行／续算、初态／AMR 预览与只读 Plotfile 查询 | 预览依模型声明能力，RZ 初始 AMR 提供根级快照；Plotfile 总览为笛卡尔一／二维，原生单元查询覆盖所记录的一至三维坐标；见[Studio 指南](guides/Studio.zh-CN.md) |
| 自定义算例 | 通过 `<UserInterface.h>` 和 `<GlobalDefs.h>` 定义 `Setup`、`Init` 与参数 | [算例指南](guides/SimulationCase.zh-CN.md)给出完整工作流 |

通用辐射输运不在当前功能范围内；热扩散和 EOS 的辐射热力学分量按各自模型使用。

曲线网格在原点／极点附近的小单元可能显著限制时间步长并增加 AMR 推进成本；近原点的精度应由相应算例的收敛检查确定。

## 自引力计算域

`gravity_type=self` 使用共享泊松数学和复合 AMR 求解流程。可用的计算域与后端见下表；引力边界、流体面边界和网格拓扑必须相容。

| 几何 | 当前能力 | 使用条件与验收范围 |
| --- | --- | --- |
| 笛卡尔 | 一至三维周期；三维孤立；CPU／CUDA | 周期引力去除体积平均密度，孤立域采用有限质量边界 |
| 柱／球坐标一维径向 | 孤立域；CPU／CUDA | 半径非负，径向内流体面反射 |
| 二维球坐标极平面 `(r,phi)` | 完整方位角孤立域；CPU／CUDA | 方位角覆盖完整一周且流体面周期，径向内面反射 |
| 二维轴对称柱坐标 `(r,z)` | Host 指定势／通量及用户引力边界 | 短程动态 AMR 与严格续算已验收；孤立场空间收敛及有限步连续能量参考已通过，完整孤立演化、动态反应 AMR 与 CUDA 运行仍待验收 |
| 三维柱／球坐标 | 完整方位角孤立域；CPU／CUDA | 柱坐标 `(r,z,phi)`、球坐标 `(r,theta,phi)`；轴线／极点使用对应的反射接合 |
| 三类几何一至三维的支持范围 | 指定势／外法向梯度／线性 Robin 及用户边界 | 非周期域、环域或扇区域；周期方向匹配 AMR 拓扑，纯 Neumann 条件要求 Gauss 相容性；后端范围沿用各几何行 |

域外质量源尚未纳入自引力计算。流体、热扩散、燃烧、自引力与 AMR 已有代表性 CPU／CUDA 耦合运行；模型与方法的具体组合条件见[方法与物理模块的组合](Reference.zh-CN.md#方法与物理模块的组合)。边界接口说明见[用户边界](guides/UserBoundaries.zh-CN.md)，受测配置、误差预算与处理后的证据见[引力验证](../validation/gravity/README.zh-CN.md)。

Jeans 场与细化指标 `JENS` 在 CPU 上支持受测的恒比热 IdealGas 均匀周期背景演化／续算，以及 Host 指定势边界的轴对称初态细化、短程输出与严格续算。笛卡尔显式 CUDA 接线已有工程实现，最终 GPU 科学验收仍待完成；一般 EOS 与非均匀引力耦合的适用范围也待验证。配置条件和 `jeans_cells` 见[AMR 与 plot 变量词汇](Reference.zh-CN.md#amr-与-plot-变量词汇)。
