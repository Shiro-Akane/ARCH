# ARCH 功能清单

[English](Features.md) · [算例指南](guides/SimulationCase.zh-CN.md) · [参数与接口参考](Reference.zh-CN.md) · [验证范围](../validation/README.zh-CN.md)

本页用于选择算例所需的能力。表中列的是现行实现；具体参数、可组合条件和科学验收范围分别见参考手册与验证记录。输入、输出和物理常数统一使用 CGS。

| 功能 | 现行能力 | 使用时核对 |
| --- | --- | --- |
| 流体 | 一至三维可压缩有限体积流体；SW、VL、Roe、HLL、HLLC 通量；PCM、MUSCL/PLM、PPM 重构；Euler、SSPRK2、SSPRK3 时间推进 | 通量与 EOS 的适配、粗细网格面的重构、耦合问题的时间精度 |
| 网格与边界 | 笛卡尔、柱坐标和球坐标块网格；周期、流出、反射、指定入流与用户物理边界 | 二维柱坐标采用轴对称 `(r,z)`；二维球坐标采用赤道极坐标 `(r,phi)`；三维柱坐标为 `(r,z,phi)` |
| 自适应网格 | 动态细化／粗化、守恒状态迁移、跨块交换和流体／扩散通量修正 | 细化指标与具体物理场的适用性 |
| 状态方程 | 理想气体、Helmholtz、规范化三／四维自由能表、受支持的原生 EOSDriver 与重子表 | 表格的物理分量声明、有效域和温度反解 |
| 扩散 | 热、黏性和组分通道；RKL1、RKL2 推进 | 系数来自所选材料模型；Helmholtz 恒星输运分支提供热传导 |
| 核反应 | iso7、aprox13、aprox19、aprox21；符合接口的生成网络；BE_NR、ROS4、BD 积分；具备模型资格时使用 NSE | 生成网络的设备数学能力、网络与 EOS 的相容性 |
| 线性求解 | 小型燃烧 ODE 使用 DenseLU；大型稀疏燃烧系统在 CPU 上可用 KLU、在 CUDA 上可用 cuDSS；自引力使用复合多重网格 | cuDSS 为可选依赖；燃烧与泊松求解器各自负责不同方程 |
| 重力 | 外部加速度与随流体状态更新的自引力势、加速度和能量功 | 自引力域与边界的具体条件见下表 |
| 执行后端 | CPU/OpenMP 与 CUDA 共用物理和数学实现；动态 AMR 在主机管理拓扑、设备执行数值任务 | 构建与网络能力决定可选后端；实际加速取决于算例规模 |
| 输出与恢复 | HDF5 流体场、检查点、求解与修复诊断；相容配置可在 CPU/CUDA 之间续算 | 恢复时须保持 EOS、网络、几何、引力与控制参数的科学身份 |
| 自定义算例 | 通过 `<UserInterface.h>` 和 `<GlobalDefs.h>` 定义 `Setup`、`Init` 与参数 | [算例指南](guides/SimulationCase.zh-CN.md)给出完整工作流 |

通用辐射输运不在当前功能范围内；热扩散和 EOS 的辐射热力学分量按各自模型使用。

原点／极点附近的曲线小格可能显著限制时间步并增加AMR推进成本；现有网格的近原点精度限制需按受测问题判断。发布沿用当前网格，径向映射和AMR网格重设计另行讨论。

## 自引力计算域

`gravity_type=self` 在 CPU 和 CUDA 上使用同一套泊松数学与复合 AMR 求解流程。`gravity_boundary` 和流体面边界须与网格拓扑一致。

| 几何 | 已验证的引力边界与维度 | 关键条件 |
| --- | --- | --- |
| 笛卡尔 | 一至三维周期；三维孤立 | 周期引力去除体积平均密度；孤立域采用有限质量边界 |
| 柱／球坐标 | 一维径向孤立 | 半径非负、径向内流体面反射 |
| 二维球坐标极平面 | 完整方位角的孤立域 | `(r,phi)` 跨完整一周；方位角流体面周期，径向内面反射 |
| 轴对称柱坐标二维 `(r,z)` | 科学验收进行中 | Host指定势／通量及用户引力边界的短程动态AMR与严格续算已有验收；孤立连续场、引力能量、动态反应AMR及CUDA仍在验收，运行受能力检查约束 |
| 三维柱／球坐标 | 完整方位角的孤立域 | 柱坐标 `(r,z,phi)`；球坐标 `(r,theta,phi)`；轴线／极点使用相应反射接合 |
| 三类几何一至三维 | 指定势／外法向梯度／线性 Robin 及用户边界 | 有效的非周期域、环域或扇区域；周期方向与 AMR 拓扑匹配，纯 Neumann 检查 Gauss 相容性 |

已有笛卡尔、径向和完整方位角范围的椭圆场、AMR、重启及选定耦合检查。历史二维柱坐标极平面记录保留原坐标语义，不作为轴对称 `(r,z)` 的验收证据。逐面 Dirichlet、Neumann、良定线性 Robin 和用户回调支持三类几何及有效扇区域；孤立质量模型仍要求完整方位角。域外质量源尚未纳入自引力能力。边界热／黏性／组分通道与后端成本见[用户边界](guides/UserBoundaries.zh-CN.md)。流体、热扩散、燃烧、自引力与 AMR 的四模块组合有代表性 CPU/CUDA 运行；每种模型替换仍应按[组合条件](Reference.zh-CN.md#方法与物理模块的组合)核对。详细的边界、残差控制和输出字段见[引力参数与接口](Reference.zh-CN.md#eos-与重力)，实测范围见[引力验证](../validation/gravity/README.zh-CN.md)。

Jeans 场与细化指标 `JENS` 已接入 CPU，当前验收包括单一恒比热IdealGas的均匀周期背景演化／续算，以及Host显式势边界RZ的初态分辨率修复、短程输出和严格续算。显式笛卡尔 CUDA 接线属于工程候选，最终 GPU 验收尚未通过；一般EOS、非均匀引力耦合和完整RZ科学出口仍待补齐。选择该指标须启用自引力和显式后端；`auto`、曲线坐标 CUDA 及非法组合会报错。配置条件与 `jeans_cells` 参数见[AMR 与 plot 变量词汇](Reference.zh-CN.md#amr-与-plot-变量词汇)。
