# ARCH v1.3.1

[中文](V1.3.1.zh-CN.md) · [GitHub release](https://github.com/Shiro-Akane/ARCH/releases/tag/v1.3.1) · [Release index](README.md)

This maintenance release updates Vite from 8.3.0 to 8.3.4 with its locked dependencies and removes local assistant instructions and completed task plans from source distribution.

## Compatibility and checks

Scientific implementation, Studio file operations and numerical tolerances are unchanged. The [v1.3.0 scientific acceptance](../../validation/backend/results/release-readiness/REL6CandidateAcceptance-20261020.json) applies to this version's Linux/WSL2 CPU and CUDA scope.

The dependency update passed [ARCH CI](https://github.com/Shiro-Akane/ARCH/actions/runs/39495458886), including Tooling, CPU Release and Studio/Host checks. The Studio suite ran 388 tests, followed by lint, TypeScript checking and the production build.

## Distribution

The release provides source. External scientific tables retain their acquisition and license requirements. See the [build guide](../guides/Build.md) for compilation and the [citation guide](../zenodo/README.md) for version-specific citation records.
