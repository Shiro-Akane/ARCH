# ARCH v1.3.1

[中文](V1.3.1.zh-CN.md) · [Build guide](../guides/Build.md) · [Studio guide](../guides/Studio.md)

This maintenance release establishes the frozen baseline after [PR #17](https://github.com/Shiro-Akane/ARCH/pull/17). Vite is updated from 8.3.0 to 8.3.4 together with the locked transitive dependencies. Machine-local assistant instructions, the project assistant skill and the completed root modernization/release plans are removed from distribution. Public documentation now points to the [frozen qualification index](README.md).

## Validation and scope

PR #17 at `25af9bc48128344215c57ec50ac7af6d3353f660` passed [ARCH CI](https://github.com/Shiro-Akane/ARCH/actions/runs/39495458886), including Tooling, CPU Release, Studio and Host, and the required summary. The Studio job ran 388 tests with 388 passes and zero failures, then lint, TypeScript checking and the Vite 8.3.4 production build. This is hosted evidence for that tested merge candidate; publication additionally requires the current release-cleanup PR and merged-main checks to pass.

The cleanup does not change scientific implementation, mathematical libraries, Studio data-reading or data-writing implementation, scientific inputs, test definitions or tolerances. The [v1.3.0 scientific acceptance](../../validation/backend/results/release-readiness/REL6CandidateAcceptance-20261020.json), its identities, historical failures and gaps remain applicable. Supported execution remains Linux/WSL2 with the recorded CPU and single NVIDIA GPU scope. Windows native execution and MPI are not implemented or qualified by this patch.

## Source and citation

This is a source release. Required external data and dependencies retain their documented acquisition and license requirements; Git LFS pointers are not replaced with fetched payloads. No prebuilt scientific binaries or raw simulation outputs are added.

The [Zenodo documentation](../zenodo/README.md) distinguishes the existing version DOI from the series DOI. Version 1.3.0's DOI must not be reused as the DOI for 1.3.1. Until the new deposit is published, `CITATION.cff` identifies 1.3.1 by its release URL and uses the established all-versions DOI `10.5281/zenodo.23503924`; `.zenodo.json` intentionally omits a version DOI.
