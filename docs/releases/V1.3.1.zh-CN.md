# ARCH v1.3.1

[English](V1.3.1.md) · [GitHub release](https://github.com/Shiro-Akane/ARCH/releases/tag/v1.3.1) · [版本索引](README.md)

此维护版将 Vite 从 8.3.0 更新到 8.3.4，并同步锁定依赖；源码分发中移除本机助手说明与已完成的任务计划。

## 兼容性与检查

科学实现、Studio 文件操作和数值容差保持不变。[v1.3.0 科学验收](../../validation/backend/results/release-readiness/REL6CandidateAcceptance-20261020.json)适用于此版的 Linux／WSL2 CPU 和 CUDA 范围。

依赖更新通过 [ARCH CI](https://github.com/Shiro-Akane/ARCH/actions/runs/39495458886) 的 Tooling、CPU Release 与 Studio/Host 检查。Studio 测试集执行 388 个测试，随后完成 lint、TypeScript 检查和生产构建。

## 分发

此版提供源码；外部科学表保留各自的获取与许可要求。编译方法见[构建指南](../guides/Build.zh-CN.md)，版本引用记录见[引用指南](../zenodo/README.md)。
