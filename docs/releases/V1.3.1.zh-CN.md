# ARCH v1.3.1

[English](V1.3.1.md) · [构建指南](../guides/Build.zh-CN.md) · [Studio 指南](../guides/Studio.zh-CN.md)

本维护版以 [PR #17](https://github.com/Shiro-Akane/ARCH/pull/17) 合并后的源码为起点，将 Studio 的 Vite 从 8.3.0 更新到 8.3.4，并同步锁定的传递依赖。分发物移除本机 `AGENTS.md`、项目 assistant skill 及根目录两份已完成的现代化／发布计划；公开文档改指向[冻结资格索引](README.md)。

## 验证与适用范围

PR #17 的 head `25af9bc48128344215c57ec50ac7af6d3353f660` 已通过 [ARCH CI](https://github.com/Shiro-Akane/ARCH/actions/runs/39495458886) 的 Tooling、CPU Release、Studio and Host 与汇总门。Studio 的 388 项测试全部通过，随后完成 lint、TypeScript 检查与 Vite 8.3.4 生产构建。这是该合并候选的托管证据；发布还要求本次清理 PR 及实际合并后的 main 检查通过。

发布清理不改科学实现、数学库、Studio 数据读写实现、科学输入、测试定义或容差。[v1.3.0 科学验收](../../validation/backend/results/release-readiness/REL6CandidateAcceptance-20261020.json)的原始身份、保留的失败与缺口继续适用。已支持范围仍为原记录中的 Linux／WSL2、CPU 和单 NVIDIA GPU；本版没有实现或验证 Windows 原生执行与 MPI。

## 源码与引用

本版沿用源码发布方式，保留外部数据与依赖的取得方式和许可。Git LFS 指针不替换成下载载荷；不附加预编译科学执行物或原始模拟输出。

[Zenodo 文档](../zenodo/README.md)区分版本 DOI 与全版本 DOI。1.3.0 的 DOI 不用于冒充 1.3.1 的 DOI。新存档发布前，`CITATION.cff` 以 release URL 标识 1.3.1，并使用已有全版本 DOI `10.5281/zenodo.23503924`；`.zenodo.json` 暂不填写版本 DOI。
