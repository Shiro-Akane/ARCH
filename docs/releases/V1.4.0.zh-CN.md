# ARCH v1.4.0：Windows 原生支持

[English](V1.4.0.md) · [版本索引](README.md) · [构建](../guides/Build.zh-CN.md) · [Studio](../guides/Studio.zh-CN.md)

发布日期：**2026-10-27** · [GitHub release](https://github.com/Shiro-Akane/ARCH/releases/tag/v1.4.0)

## 主要变化

ARCH 新增原生 Windows 11 x64 的 CPU／CUDA 命令行程序和 Studio 桌面支持。推荐 Linux；Windows 可能仍有平台相关的不稳定性和缺陷。

- CPU/OpenMP 构建采用 GCC/UCRT64 与匹配的 HDF5/KLU；CUDA 构建采用独立 MSVC/NVCC 工具链、Windows SDK 和匹配依赖。
- 两平台的 Studio 均支持配置编辑、Configure/Build、真实初始场和初始 AMR 预览、终端 Run/Restart 及只读 Plotfile 查看。
- 原生路径、进程监管、输出预留、文件发布和资源限额支持共用的科学实现与文件格式。
- Linux 与 Windows 使用相同的桌面打包流程；Electron 版本同时核对 manifest、lockfile 和已安装包。

## 依赖

此版使用 Vite 8.3.4、Electron 44.9.1 和 Undici 7.30.1。仅开发时使用的 Zod 更新到 4.6.7，修复 [GHSA-mrhx-c7xc-m3w5](https://github.com/advisories/GHSA-mrhx-c7xc-m3w5)。Studio 锁文件和依赖清单记录版本与许可。

## 兼容性与验证

Windows 与 Linux 共用数值方法、物理模型和 HDF5 格式。原生兼容修复保留公式、误差阈值与内存池行为。不同编译器 ABI 需要各自的构建目录和依赖。

[平台支持](PlatformSupport.zh-CN.md)列出已测试配置、CPU／CUDA／Studio 对照及 Windows 限制。MSVC/CUDA 的完整依赖新鲜度仍为 unknown；独立 Run/Restart 采用 Windows Terminal。科学组合和模型限制见[功能清单](../Features.zh-CN.md)与[验证](../../validation/README.zh-CN.md)。

## 分发与引用

发布包包含源码、SHA-256 校验和与 `ARCHIVE_PROVENANCE.json`。科学表文件保留 Git LFS 指针，真实数据按[构建指南](../guides/Build.zh-CN.md#source-archives-and-eos-tables)准备。Core 执行物和桌面便携包需另行构建。

引用 v1.4.0 时使用 release URL 和版本日期。对应 Zenodo 版本尚未发布；已有系列 DOI 和 v1.3.0 版本 DOI 见[引用指南](../zenodo/README.md)。
