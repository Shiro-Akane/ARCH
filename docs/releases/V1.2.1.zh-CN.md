# ARCH v1.2.1 候选说明

[English](V1.2.1.md) · [详细验收记录](../../validation/gravity/flash/O6ControlsAcceptanceReport.zh-CN.md)

本性能补丁候选减少 EOS、反应网络及后端执行中的重复工作，保留共享 CPU/CUDA
数学、完整面 EOS、守恒通量限制及两个 Strang 燃烧半步。本轮按当前实现收尾，
工程验收与跨代码成本、精度限制分别记录；原统一两倍时间目标尚未全面满足，
后续数值方法只作讨论。本说明不发布标签。

## 执行方式与数值控制

- 在不变阶段内按完整状态精确复用 EOS／网络查询。失败试探继续交回原 ODE／NSE
  恢复流程；必要查询和接受状态仍严格检查。
- 五种通量共用一份 CPU 面遍历与限制器准备；CPU 和 CUDA 消费相同面数学和均值视图。
- `hll_wave_speed=roe|davis` 适用于 HLL、HLLC 及其支持的重构，默认仍为 `roe`。
  两种选择均保留完整热力学闭合；它是方法选择，不保证对所有场景更准或更快。
- `eos_coulomb_mult` 一致缩放 Helmholtz 离子 Coulomb 项及其导数，默认保留全部修正。
  改变此项会改变物理模型；电子／正电子补齐独立处理。
- `dt_max` 可限制物理宏步。参数沿用 EOS／Runtime 分组，高级选项的折叠属于 GUI 显示层。
- Release 应用与 dispatch 共用 `-O3` 及工具链支持的 LTO／IPO。宿主移除未使用的
  libm errno 副作用，保留严格浮点求值、有限数检查及非正规数，不支持全局 fast-math。

## 迁移与限制

标准目录为 95 项。格式 6 检查点的状态控制身份更新为修订 2，包含三个新控制。
旧身份在替换网格前拒绝，不按旧默认值静默补齐。更新后须重建；已有计算使用其
原执行程序续算，或从适当的新初态启动。

面 EOS 近似未达到事前科学误差预算，未包含于本候选。默认热闭合、ODE 容差、CFL
稳定性上界及 AMR 判据保持有效。CPU／CUDA 收益依赖负载与硬件，代表性耦合检查
不等于普遍 GPU 加速，也不证明与 FLASH 的长时反应流等价。具体能力见
[参考手册](../Reference.zh-CN.md)，测量范围见上方验收记录。
