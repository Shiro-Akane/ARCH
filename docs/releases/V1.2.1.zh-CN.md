# ARCH v1.2.1 更新说明

[English](V1.2.1.md) · [功能清单](../Features.zh-CN.md) · [参数参考](../Reference.zh-CN.md) · [验收记录](../../validation/gravity/flash/O6ControlsAcceptanceReport.zh-CN.md)

本次更新减少 CPU、多物理场和自引力计算中的重复工作，并补齐配置、检查点和发布包的验证。CPU 与 CUDA 继续共用物理和数值公式；流体面使用完整 EOS，守恒限制和 Strang 分裂中的两次燃烧调用保持有效。

## 计算与执行

- EOS 与反应网络对同一阶段中**完全相同**的状态复用查询结果。不同状态继续独立求值；ODE／NSE 失败试探沿用原有恢复和验收流程。
- 五种流体通量共用 CPU 面遍历与限制器准备，CUDA 继续调用相同的面数学。自引力的 CPU 孤立边界按小批任务动态分配，降低不同边界面的计算负载差异；面内公式与求和顺序保持一致。
- Release 应用及分发目标采用 `-O3` 和工具链支持的链接期优化。严格浮点求值、有限数检查和非正规数处理保留。

## 新增配置

| 参数 | 默认值 | 用途 |
| --- | --- | --- |
| `hll_wave_speed` | `roe` | HLL／HLLC 可选 `davis` 波速估计；支持的重构方法共用此选择。 |
| `eos_coulomb_mult` | `1` | 在 `[0,1]` 内缩放 Helmholtz 离子 Coulomb 项及其导数；非默认值会改变物理模型。 |
| `dt_max` | `-1` | 可选物理宏步上限，单位为秒；`-1` 表示不增加这项限制，其他值须不小于 `dt_min`。 |

这些参数归属现有 Runtime／EOS 配置组。`dt_max` 不放宽 CFL 或燃烧限制；非默认 Coulomb 比例仅适用于 Helmholtz，非默认波速选项仅适用于 HLL 家族。网格边界与引力表达式参数现可写 `exp(number)`，如 `exp(1)`；算例自定义数值要求完整、有限的数值记号，格式错误会在读取时报错。[参考手册](../Reference.zh-CN.md)列出完整约束和单位。

## 重启、构建与文档

检查点的状态控制身份现在包含上述控制。当前身份的读写和续算、旧身份的明确拒绝，以及损坏数据的拒绝均已补测；读取失败保留活跃网格，写入前校验失败保留已有文件。旧轨迹可由生成它的执行程序续算，或从当前版本的新初态开始。更新源码后需重新配置并编译。

构建指南区分 Git 检出与源码归档的 EOS 表准备方式；干净源码归档的 CPU 构建、Helmholtz、检查点和 Sod 入口已实测。项目首页补充 `src/` 各模块的职责与后续开发方向；[独立功能清单](../Features.zh-CN.md)列出当前能力，[参考手册](../Reference.zh-CN.md)集中说明低密度状态、输入迁移与自引力边界，已完成的迁移过程材料保留在开发档案中。

## 验证与适用范围

本轮源码通过 61 项 CPU 和 135 项 CUDA 已注册检查，以及 42 组生产耦合／重启记录。三维柱坐标四模块 AMR 的配对完整进程计时，在受测主机上分别比修复前缩短 7.53%（8 线程）和 4.14%（16 线程）。同机 RTX 3060 Ti 的二维四模块算例获得 1.61 倍 CPU／CUDA 整程比；三维算例仍由受测 CPU 配置更快。这些数字只描述所列硬件、输入和物理终点。

完整输入、误差预算、源码身份和计时见[性能与精度验收](../../validation/gravity/flash/O6ControlsAcceptanceReport.zh-CN.md)及[发布补测](../../validation/gravity/flash/results/release-readiness-20260927/README.md)。长时多物理可靠性和跨软件等误差成本需要各自的验证记录。
