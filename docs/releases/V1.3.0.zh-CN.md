# ARCH v1.3.0

[English](V1.3.0.md) · [Studio 指南](../guides/Studio.zh-CN.md) · [配置参考](../Reference.zh-CN.md) · [验收记录](../../validation/backend/results/release-readiness/REL6CandidateAcceptance-20261020.json)

本次源码发布加入 ARCH Studio，完成整体架构整理，并将关键配置的静默回退改为显式验证。CPU 与 CUDA 继续共用物理和数值数学。

## ARCH Studio

选配桌面将分组参数编辑、Configure/Build、真实 Core 初始场与初始 AMR 预览、经确认的独立终端 Run/Restart，以及只读 Plotfile 查看整合为连贯流程。Inspector 显示实际存储的原生单元值、单位和产出运行身份。Preview 只执行受限初始化，正式运行仍经过 Core 启动和科学检查。界面说明见[配图指南](../guides/Studio.zh-CN.md#界面导航)；科学执行程序仍可独立使用。

## 架构与配置

- 公共数值、状态、Grid 与曲线坐标设施供两后端共用，设备存储和执行归 CUDA 适配层。几何与可选引力保持独立；轴对称二维柱坐标 r-z 沿用既有 Grid／曲线坐标设施，保留旋转与守恒 AMR，不再维护平行 RZ 实现。
- 活动关键值缺失、选项错误及非法组合明确报错；允许的默认值和自动选择保留来源记录。旧兼容别名及退役输入的静默转换已移除。旧输入应对照当前示例和[严格配置契约](../development/ConfigurationContractPlan.zh-CN.md)更新。
- 共享曲线坐标压力平衡修正了受测原始高压输入的近零动量差异，原数值门槛及严格浮点规则保持。
- 构建与测试职责、源码注释和归属索引更清晰，常规 CI 的覆盖与成本有明确边界。当前指南归一，历史说明收至 `docs/histroy/`；Runtime 安装包含声明的示例、表与许可，运行时系统依赖仍需具备。

## 验证与使用

[验收记录](../../validation/backend/results/release-readiness/REL6CandidateAcceptance-20261020.json)逐项列出 16 个公开模型及适用证据，覆盖干净 CPU／CUDA 构建与迁移安装、受影响数值与续算、真实生成网络的三种 ODE／NSE 启停及实际 Studio 操作链。388 项 Studio 测试零跳过。原长程科学证据保留各自身份与适用范围。

运行范围仍为 Linux／WSL2，本轮 CUDA 设备为 RTX 3060 Ti／sm86。SNIa 采用已接受的主终点／守恒／续算与获准的重复 AMR 补充证据联合准入，旧主算例重复 AMR 的 FAIL 与 thermal GAP 仍保留。热点功能终点不等同独立点火机制证明。完整 CUDA 编译成本仍高，已保留计时，不作普遍提速承诺。
