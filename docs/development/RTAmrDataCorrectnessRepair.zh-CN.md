# AMR 状态接受与连续重构

[RT 复现输入](../../validation/amr/inputs/rt/README.md) · [AMR 验证](../../validation/amr/README.md)

CPU 和 CUDA 共用状态接受、PPM 重构与面通量约束。后端分别负责遍历、存储和归约，数学定义与误差预算保持一致。

## 数值约束

微量负值的允许带为 Hydro 的 `64 * epsilon(double)`。合法的非负质量分数保持逐位不变。
只有可记录且可表示的负值修正才能接受；超出允许带、非有限状态、
错误组分和非法物理边界仍然报错，不作无条件截断或隐式归一化。

对修正的组分质量，记录

\[
\Delta M_s=-\rho X_s V,\qquad X_s<0.
\]

修正前检查整个单元和所有收支项，再进行写入。质量分数修正不改变
总密度、动量或能量。这里是有界、可审计的误差处理规则，并不意味着
任意负值都来自最后一次浮点减法，也不保证所有 STS 中间状态都正定。

RKL 阶段收支按完整递推传到最终状态，不能直接将各阶段修正相加：

\[
\Delta M_{\mathrm{final}}=\sum_{j=1}^{s}g_j\Delta M_j.
\]

`DiffFunction::repair_weights` 使用原有 RKL 系数计算传播权重。
有符号收支乘 `g_j`，绝对误差收支乘 `|g_j|`；事件数不乘时间权重。
紧凑收支行保存累计量和一个触发位置，而非逐单元修正场。GPU 归约
顺序可能改变触发位置或末位累计值，应将这些元数据与物理场分开核对。
现有 checkpoint 的非 Hydro 收支类别为 `stage=0`，不新增持久格式。


## PPM 极值限定器

PPM 将面值投影到连续的曲率扩展区间，并按曲率支持程度混合 CW 二比一约束与原抛物线。曲率支持参考 [Sekora／Colella](https://arxiv.org/abs/0903.4200) 的二阶差分限制方法；以下定义是 ARCH 使用的连续投影与混合，系数 `C=1.25`。

令面两侧单元平均值为 `u_i,u_{i+1}`，相邻二阶差分为 `d_L,d_R`，
定义 `k_+=max(0,min(Cd_L,Cd_R))` 与
`k_-=max(0,min(-Cd_L,-Cd_R))`。四阶插值面值投影到

\[
[\min(u_i,u_{i+1})-k_+/6,\ \max(u_i,u_{i+1})+k_-/6].
\]

单元两侧原面偏移为 `a_L,a_R`，令 `P=6(a_L+a_R)`，由三个相邻
二阶差分取得与 `P` 同号的曲率支持 `k`。将 CW 面值 `f_CW` 混合为

\[
f_{\mathrm{out}}=f_{\mathrm{CW}}+
\min(1,k/|P|)(f_{\mathrm{original}}-f_{\mathrm{CW}}).
\]

`P=0` 直接保留线性抛物线轮廓，不进行除零；CW 改变量受 `|P|/6`
约束，因此该零曲率连接连续。常量、线性和精确二次曲线的有限体积
面值保留。数学实现只位于 `Reconstruction.h`，没有增加 CUDA 公式；
组分面归一化、EOS 查询、正定性射线限制及一阶回退保持原有职责。


## 组分与流体通量

面通量约束使用与状态接受相同的组分锥。令
`tau=composition_roundoff_limit`，使用同一组分锥

\[
q_s+\tau\rho\ge0,\qquad q_s=\rho X_s.
\]

给定低阶中间状态 `B` 和流体修正 `C=(F_low-F_high)/a`，定义

\[
Q_s=B_{q_s}+\tau B_\rho,\qquad
D_s=(f_{s,\mathrm{low}}-f_{s,\mathrm{high}})/a+\tau C_\rho.
\]

沿用同一个流体／组分混合比例，要求 `theta*|D_s|<=Q_s`，便同时
约束两侧的 `Q_s±theta D_s`。密度与内能仍使用原有严格正定性约束。
这使极小组分不再通过零分母／零界限切换有限流体通量；可表示的
负微量仍须在阶段接受时记录修正，不能作为未记录的截断。
该局部 Euler 论证依赖现有 CFL 与合法低阶状态，
不扩展为任意 RKL 中间阶段或任意表格 EOS 的正定性定理。


## 验证与结果解释

局部测试覆盖常量、线性和二次曲线、跨尺度扰动、间断、反射、严格流体边界和组分守恒。RKL 权重使用独立脉冲递推核对；实际 RT 输入验证多次 regrid、质量收支、相同物理时间的后端比较和同后端重启。

近零动量的纯相对诊断应同时报告绝对差。场比较使用原有绝对加相对预算，时钟与拓扑也需满足比较条件。局部重构检查、短程 RT 对比和完整物理终点各有适用范围；长期演化应使用相应的收敛与守恒检查。
