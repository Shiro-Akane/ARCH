# RT／AMR 数据正确性修复与采集准入

本轮以 `main` 的 `25adec4224497981a0c124a3485f786194975be4` 为基线，
优先解决阻碍 GNN 数据采集的状态错误。合作者提供的复现材料位于
`codex/rt-amr-validation-notes-20261003`，目前核对到 `2ee826655`。
共用修复先在独立工作区验证，再以定点补丁接入 `codex/o8-boundaries`
的 `095b3c3ee`；保留该分支的边界接口、可选收支观察器与缓存优化。
本轮不向 main 合并其他开发分支，也不覆盖 O8 的独立工作。
补丁只包含共用数值修复、必要的后端接线、测试与复现说明，不包含
GNN 模型、训练、数据集生成器或预测 AMR 实现。冻结的科学基线仍为
上述 main 提交；O8 只是本轮定点补丁的交付分支。
四份可移植复现输入及 restart 方法已整理到
[validation/amr/inputs/rt](../../validation/amr/inputs/rt/README.md)。

## 目标和回查顺序

1. 使用四份实际输入复现原有错误，不以修改算例代替修复。
2. 在共用数值库中完成有记录的微量组分修正。CPU 和 CUDA 使用同一
   判断、公式和物理边界；只有遍历、内存、归约及 kernel 调度分离。
3. 检查 Hydro 最终 reflux 和 RKL 内部阶段、reflux 的接受顺序与质量
   收支。非法状态必须在发布前拒绝，完整步骤失败时不提交成功收支。
4. 以相同输入定位 CPU／CUDA 的场分歧，区分浮点差异、不同物理时间、
   拓扑变化以及真正的数学／实现错误。保留原有诊断门槛，不放宽门槛
   来换取通过。
   本轮同时修正共用 PPM 的极值限定器，并重新运行相关科学验证。
5. 完成针对性回归、四组轨迹、包含多次 regrid 的较长演化、restart
   和适当的独立解析参照，再决定能否恢复数据采集。

完成复现、共用数值叶验收、后端分歧定位，以及采集准入判断之前，都
应回读以上目标。本轮不包含完整 RT 终点、所有大型网络、GNN 模型自身
或后续全部优化的冻结验收。

## 数值约束

微量负值的允许带沿用现有 Hydro 的 `64 * epsilon(double)`，没有添加
新的用户开关、组分下限或网络特例。合法的非负质量分数保持逐位不变。
只有可记录且可表示的负值修正才能接受；超出允许带、非有限状态、
错误组分和非法物理边界仍然报错，不作无条件截断或隐式归一化。

对修正的组分质量，记录

\[
\Delta M_s=-\rho X_s V,\qquad X_s<0.
\]

修正前检查整个单元和所有收支项，再进行写入。质量分数修正不改变
总密度、动量或能量。这里是有界、可审计的误差处理规则，并不意味着
任意负值都来自最后一次浮点减法，也不保证所有 STS 中间状态都正定。

RKL 阶段收支按完整递推传到最终状态，不能直接将各阶段修正相加：

\[
\Delta M_{\mathrm{final}}=\sum_{j=1}^{s}g_j\Delta M_j.
\]

`DiffFunction::repair_weights` 使用原有 RKL 系数计算传播权重。
有符号收支乘 `g_j`，绝对误差收支乘 `|g_j|`；事件数不乘时间权重。
紧凑收支行保存累计量和一个触发位置，而非逐单元修正场。GPU 归约
顺序可能改变触发位置或末位累计值，应将这些元数据与物理场分开核对。
现有 checkpoint 的非 Hydro 收支类别为 `stage=0`，不新增持久格式。

## PPM 极值限定器

原有平滑极值判据会在满足曲率比例后直接跳过 CW 限制。
一个全部为正的模板中，两个末位的输入变化
`2.2204460492503131e-16` 会触发约 `0.00520833` 的面值跳变。
这说明该开关具有可复现的数值敏感性，并非 GPU 独有的实现。

另两个正值模板确认，面区间判据及极值／CW 切换也会产生有限跳变。
因此修正不再依赖这些二值开关。面值投影到连续的曲率扩展区间，
单元内则将 CW 二比一约束与原抛物线按曲率支持程度连续混合。
曲率支持参考 [Sekora／Colella 的二阶差分限制思路](https://arxiv.org/abs/0903.4200)，
但以下连续投影／混合是本项目明确规定的方法，不宣称逐式复现其
条件分支算法。统一的数值方法系数为 `C=1.25`。

令面两侧单元平均值为 `u_i,u_{i+1}`，相邻二阶差分为 `d_L,d_R`，
定义 `k_+=max(0,min(Cd_L,Cd_R))` 与
`k_-=max(0,min(-Cd_L,-Cd_R))`。四阶插值面值投影到

\[
[\min(u_i,u_{i+1})-k_+/6,\ \max(u_i,u_{i+1})+k_-/6].
\]

单元两侧原面偏移为 `a_L,a_R`，令 `P=6(a_L+a_R)`，由三个相邻
二阶差分取得与 `P` 同号的曲率支持 `k`。将 CW 面值 `f_CW` 混合为

\[
f_{\mathrm{out}}=f_{\mathrm{CW}}+
\min(1,k/|P|)(f_{\mathrm{original}}-f_{\mathrm{CW}}).
\]

`P=0` 直接保留线性抛物线轮廓，不进行除零；CW 改变量受 `|P|/6`
约束，因此该零曲率连接连续。常量、线性和精确二次曲线的有限体积
面值保留。数学实现只位于 `Reconstruction.h`，没有增加 CUDA 公式；
组分面归一化、EOS 查询、正定性射线限制及一阶回退保持原有职责。

新的局部测试覆盖常量、线性和二次曲线的单元平均值、上述扰动反例、
反向与缩放模板，以及间断控制；原有低密度数学测试继续使用原断言。
百万个有限模板的独立扰动扫描中，最大面值变化为约 `3.6e-15`。
实际 CUDA 的 450 个正反向／跨尺度扰动模板与 Host 逐位一致，
并通过原有 `64epsilon` 的预算；同一测试会拒绝仍有跳变的候选。
这些有限精度检查不构成所有输入的稳定性或正定性定理，也不能直接
证明它已解释全部 RT 分歧；最终采集结论仍来自修改后的实际演化。

## 组分通量与流体通量的连续约束

连续 PPM 的局部检查通过后，实际纯 RT 仍在第 16 步出现新的场差异。
第 15 步的状态中，约 `1e-189` 的示踪组分会改变共用通量限定器的
全流体混合比例：流体高阶能量通量原本一致，经过限定后却产生约
`5.1e-6` 的有限差异。因此仅修正 PPM 还不足以恢复采集。
独立的正定输入探针也确认，零组分均值配合任意小的非零面组分
通量，会将所有流体通量切换到低阶结果。

修正将面通量约束与现有状态接受带统一。令
`tau=composition_roundoff_limit`，使用同一组分锥

\[
q_s+\tau\rho\ge0,\qquad q_s=\rho X_s.
\]

给定低阶中间状态 `B` 和流体修正 `C=(F_low-F_high)/a`，定义

\[
Q_s=B_{q_s}+\tau B_\rho,\qquad
D_s=(f_{s,\mathrm{low}}-f_{s,\mathrm{high}})/a+\tau C_\rho.
\]

沿用同一个流体／组分混合比例，要求 `theta*|D_s|<=Q_s`，便同时
约束两侧的 `Q_s±theta D_s`。密度与内能仍使用原有严格正定性约束。
这使极小组分不再通过零分母／零界限切换有限流体通量；可表示的
负微量仍须在阶段接受时记录修正，不能作为未记录的截断。
没有新增容差、组分物理下限、用户开关或网络特例，科学与诊断预算
也没有修改。该局部 Euler 论证仍依赖现有 CFL 与合法低阶状态，
不扩展为任意 RKL 中间阶段或任意表格 EOS 的正定性定理。
