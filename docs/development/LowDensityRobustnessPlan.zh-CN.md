## 1. 行业做法与 ARCH 的选择

不存在适用于所有物理问题的统一“极小值”。常见做法是集中提供有默认值的物理下限，
将它们与浮点误差、算法参数、模型适用域和失败恢复分开。下表是查阅所得事实；
后文的接口、阶段和预算是针对 ARCH 的工程设计，不是其他项目的标准要求。

| 来源 | 已核对的处理方式 | 对 ARCH 的启示 |
|---|---|---|
| [Athena++ 绝热 Hydro EOS 源码](https://raw.githubusercontent.com/PrincetonUniversity/athena/main/src/eos/adiabatic_hydro.cpp) | `hydro/dfloor`、`pfloor`、`sfloor` 可配置；状态转换和界面状态使用集中持有的下限；压力修复相应调整总能量。 | 源码内可以有默认值，但不应在每个消费者里另写不同下限。其他代码的单位和默认数值不能直接照搬。 |
| [Castro 运行参数](https://amrex-astro.github.io/Castro/docs/runtime_parameters.html) | 密度、温度、压力、比内能具有命名参数；ambient 状态也单独配置。 | 状态 floor、物理背景介质和“不参与某物理模块”的开关不是同一概念。 |
| [Castro 步长与重试](https://amrex-astro.github.io/Castro/docs/timestepping.html) | 对负密度、异常组分、燃烧失败等返回失败并按其积分方法重试；低密度豁免是另外的显式参数。 | 失败要进入控制流；ARCH 不照搬其 AMR 时间子循环或静默豁免。 |
| [Enzo Hydro 方法](https://enzo.readthedocs.io/en/latest/physics/hydro_methods.html) | 可将失败通量回退到更耗散的方法；dual-energy 针对总能量远大于热能的问题。 | 通量回退和能量消减误差必须分别处理，不能期待 density floor 同时解决两者。 |
| [Enzo-E 参数](https://enzo-e.readthedocs.io/en/main/param/#fluid-props) | 将 EOS、floors、dual-energy 集中在流体属性中，旧方法私有参数迁往共同配置。 | 同一份有效配置服务所有消费者，避免每个求解器一套旋钮。 |
| [Hu、Adams、Shu 的正性通量限制方法](https://arxiv.org/abs/1203.1540) | 对可能破坏密度、压力正性的高阶通量进行限制，与一阶通量组合，并有相应时间步条件。 | 优先修正共享面通量以保守地控制状态；不能把更新后逐格截断称为正性守恒算法。 |

[Clawpack 的 Euler Riemann 示例](https://www.clawpack.org/riemann_book/html/Euler_approximate.html)
也展示了 Roe 在强稀疏波中的正性问题和 HLLE 的改善。该结论有方程、波速与离散条件，
不能仅因 ARCH 的函数名含 HLL 就认定当前完整 RK、源项、AMR 组合已保持正性。
网页/分支为 2026-09-22 查阅版本；实施时把实际采用的算法文献和依赖版本纳入证据。

## 2. 支持目标与非目标

### 2.1 分开验证三种困难

1. **绝对量级小**：rho、p、动量和总能量密度很小，但速度、温度、比内能正常。
   这是固定 CGS 阈值最直接破坏的场景，应优先修复。
2. **空间密度反差大/强膨胀**：即使每个输入值都有限正值，重构、Riemann 中间态或更新也可能失去正性。
   需要正性控制、受控通量回退及稳定性约束。
3. **热能相对于动能很小**：`E - |m|²/(2 rho)` 的相消会丢失热能信息。
   与密度大小不是同一问题；提高 floor 不能恢复已经丢失的信息。

| 场景 | P1.5 目标 |
|---|---|
| 有限正密度、可恢复热力学状态、处于选定 EOS 有效域 | 正常推进；不能因小于隐藏的 `1e-12` 而关闭压力、通量、CFL、引力或扩散。 |
| IdealGas 的低密度/近真空、强稀疏波 | 建立独立参考、正性、收敛和守恒验证；支持组合按实测登记。 |
| Helm/表格 EOS、燃烧、物理导热 | 只在模型有效域内检验正确性；越界有明确状态，不强行宣称所有模块都支持任意低密度。 |
| 精确真空 `rho=0`、流体—真空自由边界 | 当前守恒状态/EOS 接口不支持；明确拒绝。未来需要独立真空 Riemann/边界方案。不能以 `rho_floor` 替换零后宣称解决精确真空。 |
| 接近浮点下溢/上溢的输入 | 压力测试要求得到可解释结果或明确失败，不承诺所有正 double 都可计算。 |
| 热能低于当前总能量表示的可靠分辨能力 | 测量并报告边界，不能用 floor 冒充正确温度；dual-energy 另列状态布局扩展。 |

正密度大气是数值/物理背景介质，需要给出质量、压力及 floor 敏感性；
连续介质模型在稀薄环境是否适用还依赖温度、尺度和碰撞过程，不能由某个 rho 数字单独判断。
本阶段验证离散方程和软件行为，不把极低密度算术压力测试当作稀薄气体物理认证。

## 3. 参数与内部常数的边界

### 3.1 配置面预算：P1.5 不新增物理自由度或算法微调项

沿用现有参数名和默认值，普通用户无需逐项配置数值保护；有具体物理尺度需求时，才覆盖已有下限。
删除已确认无效键和旧别名，补登记已生效的 `dt_init/dt_min/tstep_change_factor` 为 Advanced；
这三项原本即可输入，不是新增控制行为，也不要求增加三份可独立修改的配置副本。
默认值、元数据和运行配置保持一份权威语义，已有结构初始化与解析路径不得另发展不同默认值。
“提供兜底”不等于密度、质量分数、温度和矩阵主元共用一个数；它们的量纲与作用域不同。

| 类别 | 用户接口方向 | 内部规则 |
|---|---|---|
| 流体密度下限 | 保留 `sml_rho`，g/cm³；集中管理默认值 | 配置是状态允许/修复边界，不是力、通量或 CFL 的停用密度。`rho == sml_rho` 是有效边界值。 |
| 比内能范围 | 保留 `min_eint/max_eint`，erg/g | 与 EOS 能量参考和有效域共同解析；不在 HLL/Roe/PPM 中另设 `1e-8/1e-13`。 |
| 压力/温度下限 | P1.5 不增加独立旋钮 | 由 EOS 和现有状态约束确定有效边界及一致状态；无法同时满足时明确拒绝，不静默修改用户配置。`smallt` 仍是燃烧相关参数，不能偷换成全局 Hydro 温度下限。 |
| 状态兜底与失败 | 库内固定顺序，不新增 `state_repair_policy` 或 `abort/floor` 选择 | 先作保守数值保护，再对有限且可恢复的状态应用已有下限并记账；NaN/Inf、非正密度、EOS 越界、不可分辨热能等明确失败。详见第 5 节。 |
| 组分下限/燃烧范围 | 复用 `smallx`、`smallt`、`nuclearDensMin/nuclearTempMin` 等现有参数 | 同义消费者共用现有值；质量分数、摩尔丰度、燃烧启用范围仍分别定义。复用边界见第 3.2 节。 |
| 求解容差 | 保留已有 ODE 容差，P1.5 不增加分母/主元容差键 | atol 有相应量纲，rtol 无量纲；不共用全局 `EPS`。P2 的 MG 收敛目标属于独立求解接口，提供可用默认值，内部退化判据不随之全部暴露。 |
| 舍入/退化判据 | 方法专有内容封装在算法内部 | 按相应变量/项的尺度与机器精度设计，具名集中在算法所有者内；零尺度分支明确，不能给所有分母加 epsilon。责任是推导和验证，而不是要求用户调到能运行。 |
| 几何奇点 | 不增加 `r_epsilon` 等通用用户补丁 | 使用网格几何、位置和解析/离散极限；角度、长度与网格容差分别处理。 |
| 步长停止与重试 | 保留既有工程停止限制，不新增重试参数 | 区分 `dt_min` 与 `t+dt==t`；不得暴露尚未实现的自动重试功能。 |

现有 rho/e floor 默认数字作为待验证基线，说明它们不是所有科研算例的推荐值；不为保旧结果拒绝合理修复。
启动时报告有效值、默认来源、EOS 域和初始最小值；初始态触发可恢复兜底时报告初始修复量，
无法满足模型域时拒绝。不自动按初始最小密度猜 floor，也不静默全局调低默认值代替修复。
当前 `sml_rho=1e-12` 的默认值不能同时承诺保留 `rho=1e-20` 的原状态；这种科研算例应在输入中
覆盖已有 `sml_rho`，使其低于目标解范围，其他算法保护无需跟着手调。默认工作流和极低密度工作流分别验收。

从过去的隐式裁剪改为受约束、可追踪兜底仍属于数值行为变更，须有迁移说明、有效配置及 restart 身份，
不承诺逐位保持旧结果。退役键直接移除并明确拒绝，不提供转译/兼容运行；无效参数在运行前拒绝。
将来确需新物理控制量时另行论证，不把本阶段的内部安全系数和测试容差提前变成用户 schema。

### 3.2 `smallx` 的复用边界

当前 `BurnConfig::smallx` 默认 `1e-20`，定义为质量分数下限；三种 ODE 已有消费者，优先统一其语义和实现。
复用现有 `BurnConfigView` 等轻量视图传递必要数值，不令 Hydro 数学叶函数依赖整个 Burn/SimConfig。

- `TimmesNetworkSupport::SetupInitialFractions` 的固定 `1e-20` 是同义整合候选；应读取已有 `smallx`，
  同时审查当前“给每个输入加种子再归一化”的行为。不能仅替换字面量后保留“全未指定/全零组成变均分”的问题。
- `smallx` 只用于确需非零质量分数的网络初始化/燃烧工作态或已定义的接受态规则。
  Hydro 中某物种的零质量分数和非负微量输运本身可以合法，不给每个网格无条件填充 `smallx`。
- 按实际变量语义审查调用点：数组名为 `Y` 不证明其存的是摩尔丰度。确为 `Y_i=X_i/A_i` 时，
  相同质量分数约束对应 `smallx/A_i`；来源公式的独立 `1e-30` 摩尔保护不因此自动替换。
- 对要求全部 `X_i >= smallx` 的状态，检查有限性及 `0 < N_species*smallx < 1`，
  同时满足组分和为 1；“先截断再统一除总和”可能再次跌破下限，不能当作已证明满足约束。
  对仅使用工作态种子的路径单独定义作用范围，不把种子操作冒充接受态保证。
- 单个舍入级负组分是否可恢复由算法内部误差尺度判断，不能用 `smallx` 接受任意负值。
  全零、显著负值或明显失去归一性的组成需要失败/已验证回退，不能静默制造组成。
  接受态组分调整记录各物种质量及热力学/反应能量影响，工作态修正与接受态账本分开。

### 3.3 算法内部兜底的工程要求

每个内部判据在所属实现旁说明用途、量纲/局部尺度、适用条件、触发后的动作和测试依据；
仅在真实共享时抽取具名常量或 helper，不建立包含所有物理量的 `SmallValues` 参数袋。
Riemann 分母、斜率退化、矩阵主元、Newton 进展等由各方法所有者选择并验证，
对可表示良态输入优先缩放、稳定公式或已验证的回退，不单纯把分母改成一个固定下限。
以独立参考、跨尺度、边界邻值、正常域回归和 CPU/CUDA 一致实现提供兜底证据；
内部系数在证据中可追踪，但不变为 GUI 表单，也不允许靠调参掩盖失败。

## 5. 数值流程与失败策略

### 5.1 接受状态与计算顺序

1. 初始化和每个实际修改状态的阶段均区分候选态与接受态；先检查有限性、有效密度和组分。
2. 恢复速度/热力学时避免不必要的 `m*m`、`rho*rho` 下溢及 `1/rho` 上溢；
   可考虑 `m/rho`、缩放范数及 `m dot v/2`，但必须测试舍入与相消，不能声称一次改写覆盖全部量级。
3. 在有效 EOS 域内取得压力、声速、导数；失败返回原因，不能以零压力或理想气体值冒充成功。
4. 重构、Riemann、CFL、源项和输出消费同一状态解释；不能各自临时抬高某个分母。
5. 更新后的候选态在必要状态检查、显式修复与报告完成后发布；错误输出不能标为可重启接受态。

新状态报告至少区分：有效、已作显式 floor 修复、EOS 越界、非有限、非正密度、
组分不合法、热能分辨能力不足、反解未收敛、稳定性/正性失败。
可恢复的界面重构失败和不可恢复的单元均值错误不能混成同一个状态码。

### 5.2 近真空的正性与保守通量

默认方向：先限制高阶重构偏差，再对仍不可靠的面使用经验证的同 EOS 低阶通量；
需要保证更新后正性时，采用有推导的面通量限制，不能只依赖事后 floor。
IdealGas 首先建立 LLF/HLLE 参考路径及相应多维 CFL 条件；目前 HLL 共用的 Roe/kappa
截断也需先清理，不能把它直接当作独立正确参照。

每个共享面采用双方一致的有效通量和限制系数；两侧单元约束、跨块重复面、粗细界面与组分
质量通量必须一起处理。最终通量确定后再写 flux register；若重算则撤销或覆盖先前贡献，
不得重复累加。reflux 后重新判定状态，不能悄悄跳过某格守恒修正。
RK2/RK3 的阶段权重、CFL 和源项也进入正性分析，不能从单个 Riemann 求解器推广出整步保证。
一般 EOS 的正性域/稳定性需要单独验证；未满足适用条件时明确失败，不静默更换 EOS。

### 5.3 floor 是带预算的显式修复

运行时只有一套内置处理顺序，不要求用户在严格/修复模式之间选择。
先执行第 5.2 节保守保护；仍低于配置下限、但有限、正密度且可可靠恢复的状态，
自动应用现有下限并记账。密度修复优先保留恢复出的速度和组成；
按有效内能下限重建能量，同时记录所有守恒量变化。
只有可信的低内能才可抬至下限；已因动能相消而失去热能信息的状态属于不可恢复，不能借此伪造温度。
若特定模型需要清零速度或重设背景组成，必须另行定义物理策略，不能作为无提示的通用回退。
若候选态本身不可恢复，则拒绝；不从 NaN/Inf 或零密度猜测一个材料状态。
`max_eint` 仍是显式范围约束，超上限默认失败；若需要上限裁剪，须作为另有说明和记账的策略。
超出模型速度范围或导致算术溢出的状态应被识别，不以隐藏速度上限改变动量后继续宣称原方程解。

分别记录 `sum(delta M)`、`sum(abs(delta M))`、动量向量变化、
`sum(delta E)`、`sum(abs(delta E))`、组分质量变化、触发次数/体积/位置与阶段。
净改变量接近零不能掩盖相互抵消的大量修复；阶段修复增量须按实际 RK 组合传播，
拒绝的候选操作只计尝试诊断，不能重复计入接受态累计预算。
守恒账本满足“接受态变化 = 物理边界/源项积分 + 明示修复 + 离散/舍入剩余”。

诊断采用线程局部/设备块级汇总和已有归约入口；不逐单元打印、不逐单元 D2H。
有效配置、算法修订、累计修复量在输出/证据中保存；restart 不丢失累计信息，
缺少当前必要身份/诊断字段的旧 checkpoint 直接拒绝，不能补零后当作完整历史；不再增加兼容 reader。
运行摘要明确报告是否触发兜底、覆盖范围和改变量，不新增逐项告警/允许修复比例的用户旋钮。
程序完成不自动等于科学验收：基准测试在同一生产路径上断言是否允许兜底及预算，见第 7 节。

### 5.4 有界失败、自动重试和 dual-energy

所有 Newton/回退循环有最大次数、进展判据和最终残差验收。严格失败发生在结果发布之前；
并行线程/设备以状态汇总返回，不在 kernel 内抛异常或把失败 token 标成成功。
已有 generic `BeforePublish` 只是接入点，不代表已经实现全宏步回滚。

首轮不新增通用自动重试。未来若启用，必须覆盖 Hydro slot、ghost、flux register、
Burn/Diffusion 已执行半步、阶段时钟、修复预算和输出，证明拒绝步骤没有副作用后再定义统一默认行为；
不预设需要把方法专属重试细节暴露为用户参数。
在此之前给出有界失败，不能局部重算 Hydro 然后继续已被源项修改的宏步。

dual-energy 属于独立的受输运能量/熵状态扩展，涉及 FluidState、AMR、GPU、reflux、
源项和 checkpoint；修复实施阶段先测量高 Mach 下的热能恢复误差并冻结支持边界。
若目标近真空算例必须依赖它，增加明确子阶段后再宣称该算例通过，不能放宽温度验收掩盖问题。

## 7. 验证矩阵与证据

### 7.1 测试轴与误差尺度

- **绝对量级**：IdealGas 组件先扫描 rho=`1,1e-12,1e-20,1e-30,1e-60,1e-100` g/cm³。
  保持速度、温度、组成不变；p、动量、E 与 rho 一起缩放。后两档是算术压力测试，不是物理适用性声明。
- **完整推进**：固定物理问题后，至少覆盖基准密度和 `1e-12/1e-20/1e-30` 量级的等价无源 Euler 问题；
  floor 取低于整个参考解密度范围的显式数值，不能让 floor 主导“通过”。
- **边界值**：配置 floor 的相等值及相邻浮点数；旧 `1e-12/1e-13` 位置；零、负值、NaN/Inf、
  极小可表示数及可能溢出的动量。后一类允许明确拒绝，不允许挂起或伪成功。
- **空间反差**：安排密度比 `1e6/1e12/1e18` 的分层压力测试，记录每档温度、Mach、最小压力和 EOS 域。
  高反差失败必须标清原因，不能把所有反差档位自动登记为已支持。
- **Mach 轴**：独立扫描热能/总能量比，分开统计相消与低密度误差；无法恢复热能的范围不计入通过能力。

Euler 的量级比较以 `rho_ref`、`rho_ref*c_ref`、`rho_ref*c_ref²` 分别归一化密度、动量和能量密度；
参考尺度在测试输入中给出，不通过 `max(abs(q),1)` 让所有低值误差自动通过。
这只是测试/内部算术缩放，用户输入输出仍为 CGS。
自引力在固定 G 下不会保持相同加速度，真实导热和燃烧也随密度变化；这些系统不能套用无源 Euler 的缩放不变性。

### 7.2 必需检查

下表的“零修复基准组”和“兜底触发组”是验证分类，不是新增用户模式。
两者运行相同生产实现：前者以不触发 floor 的输入检查零修复计数及正确解，
后者有意触及已有下限以核对修复结果与账本；不可恢复组验证明确失败。
同时覆盖“不写相关参数、采用现有默认值”及“只覆盖已有物理下限”的工作流，
不得通过测试专用执行开关绕过生产兜底，也不允许用户手调内部系数才能通过。

N0 的最小覆盖应包括所有现有 Hydro flux/reconstruction 路线的良态与量级组件测试；
完整近真空科学基准先覆盖 IdealGas、Cartesian、HLL/HLLC 与 RK2，比较 PCM/MUSCL/PPM，
另加 Euler/RK3 的时间检查、2D/3D 多块小规模推进和动态 AMR 场景。
其他 flux 路线需验证其近真空回退或明确的适用边界，不能因主基准通过就标为全面支持。
原有正常域路线保持回归，不删除已有功能来缩减矩阵；具体组合和科学观测量在 N0 manifest 中列明。

| 编号 | 内容 | 主要验收条件 |
|---|---|---|
| NV-01 状态与阈值边界 | floor 等值/邻值，异常 rho/e/X，全部公共消费者；`smallx`、X/Y、零物种及归一化 | 有效状态一致；同义路径复用既有值；要求下限时归一化后仍满足；异常有明确状态；无除零/非有限伪成功/无限循环。 |

| NV-07 AMR | 跨块平流、粗细面输运、refine/coarsen/reflux，低密度下限处 | 共享面有效通量一致，正性/守恒/阶数成立；零速度显示和错误细化不再出现；失败不半发布。 |

| NV-12 正常域与成本 | 原有 none/external、Hydro、AMR、扩散、燃烧及受影响 API | 已有正确物理预算保持；新诊断无逐格同步，报告普通算例与回退频繁算例的成本。 |

上述数字是本工作包的初始验收目标，不是通用应用误差保证；既有更严格的预算继续执行。
N0 必须把具体输入、终止时间、分辨率、积分器/EOS 组合和参考生成方式登记到测试 manifest，
并在候选实现运行前固定预算。不得看过失败结果后只放宽阈值、增大 floor、跳过低密度格或删掉案例。
算法适用性确需改动时，记录推导、独立参照与支持范围变化，不能只更新 expected 以求通过。

触发 floor 的应用例至少再用已有参数做三档 floor 敏感性实验；同时报告全域误差、预先固定的科研测量区域误差、
修复质量/能量及主要科学观测量随 floor 的变化。每个案例的修复预算由 N0 按科研目标冻结，
不设一个对所有问题通用的“允许修复百分比”。

## 8. GUI、合并与后续自引力

GUI 继续读取 Core 的既有参数、单位、域和失败诊断，不自己复制小值规则。
失效控件删除，已有宏步控制补入 Advanced；有效下限、修复摘要和算法身份作为只读元数据/诊断。
新 Core/GUI 使用新契约，不要求旧输入或旧 EOS 继续可用；不匹配时明确拒绝。配置检查、初始预览、完整模拟可运行性仍分别表达。
检查点记录有效策略及算法身份；不要仅为新的诊断累计字段无理由增加流体传输计数。
数学修复和 CUDA 适配分开可审查提交，但不能长期保留不同数值语义；合并依据冻结提交和共同所有者，
不持续追逐开发分支每一次 push。

P2 使用本阶段建立的有限性、尺度/残差和失败状态经验，但不依赖整个 Hydro 或燃烧栈。
Poisson 的零 RHS 是有效数学输入，不能因流体接口不支持零密度真空而禁用独立椭圆零 RHS 测试。
自引力质量源默认是接受态的全部流体密度，包括显式大气；不能按隐藏 cutoff 忽略它，
也不能未经新物理模型约定就减去 density floor。周期问题扣除平均密度是相容性条件，与此不同。

P4 的推荐方向是与 Hydro 质量通量一致的引力功，并冻结 RK 阶段推导、势的时间中心化与 AMR 校正。
阶段前准备足以提供输入引力场，但该守恒能量方案还需要候选密度后的势场/能量完成点；
可评估使用 scheduler 现有 `BeforePublish` 接口，不把未完成能量的候选态提前发布。
最终 reflux 或 floor 改变密度后，场失效和能量预算必须同步处理；仅重解 phi 不等于能量已修正。
计入 `1/2 integral(rho*phi)` 时，同时记录人工质量/能量变化及边界项，避免误归因于 MG。
