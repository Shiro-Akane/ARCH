# P5–P7：孤立边界、共用数学的 CUDA 与耦合验收

2026-09-23；工作基线 `253e1c51`，分支 `physics/selfgravity`。状态：P5–P7 基本验收完成；源码身份为包含本记录的提交。
本次授权完成 P5–P7、保留通用标准算例、更新已有验证入口，并按既有工作方式封包推送。
以下边界与预算在实现前冻结；实际结果和限制记录在末尾，历史失败不覆盖。

## 不变约束

- 只有一套数学：复合面 stencil、边界矩、MG transfer/smoother/bottom、Krylov
  控制和引力源项公式在公共目录拥有。CUDA 只实现设备分配、并行遍历、归约、传输与同步。
  优先提取并复用 P2/P3/P4，不能复制一套 CUDA Poisson 或燃烧/扩散公式。
- 单元密度来自每个真实 RK 输入；燃烧、扩散、reflux、regrid 后按实际版本重建。
  不使用旧势继续失败的推进，不通过放宽残差、物理预算或修复质量/能量来通过测试。
- 沿用 GravityConfig 的四个已发布控制；边界扩充为 periodic/isolated。
  物理配置不增加高级分组或平滑次数等算法旋钮。
- 隔离边界限三维 Cartesian；不得把零 Dirichlet 当孤立引力，不去掉孤立源的平均密度。
  流体边界和势边界分开；无外部质量的有限域近似及开放流体的边界收支必须说明。

## 实施顺序

1. P5：扩展现有 CompositePoisson 的物理边界面与非齐次 RHS；复用独立 MG 层次。
   用源树的质量/二阶矩评估孤立边界；局部展开避免全局多极要求所有质量位于内接球内。
   数学求值在 Host/Device 共用，内部开角/阶数须用直接求和和敏感性检查验证。
2. P6：提取现有 MG/FGMRES 为共用执行流程，CPU/CUDA 只替换向量/算子执行原语。
   拓扑与 stencil 缓存按 epoch 重建；全域密度、势、力与迭代向量留在 device。
   只为收敛/时间步读取标量，为输出显式下载字段；禁止每周期复制全域到 Host。
   设备粗解复用现有小型 LU 所构造的算子，不在粗层反复搬运流体或引入全域 KLU/cuDSS。
3. 耦合：保持 `B(dt/2)-D(dt/2)-H(dt)-D(dt/2)-B(dt/2)`；引力是 H 的阶段源。
   燃烧改变能量和组分、扩散改变动量/能量/组分，后续 Hydro 必须读更新后的状态。
   验证核能账本、耗散转化、物种守恒和引力功；只有通过的组合才开放。
4. P7：加入通用自引力气体算例与周期/孤立/耦合参数示例，更新配置目录、能力、
   IO/restart/单位说明及当前实施计划。合并到既有 gravity 验证程序与 CTest 入口；
   CI 作业数量不增加，重复检查改为代表性约束检查，重型矩阵与计时保留为本地验收。

## 冻结的基本预算

- 保留 P3/P4 的周期解析、空间/时间阶、质量及能量门槛，不降低历史门槛。
- P5 光滑三维源：制造解势及面力三档空间阶至少 1.8；包含边界与粗细面单列误差。
  球对称与偏心/非球源分别验证，直接边界求和作独立见证；标准开角相对边界误差
  目标不超过 `2e-3`，收紧开角/提高矩阶应趋近直接参考。扩域后内区物理解误差降低。
- CPU/CUDA：同输入、同物理时刻、同残差标准；归一化场量 `rtol=2e-8`、
  `atol=2e-10`（先按各自物理尺度归一化），同时通过各自独立解析或守恒检查。
  非线性动态 AMR 拓扑分歧若发生，比较共同物理覆盖，不能比较不对应的扁平数组。
- 耦合：分别验证 self+diffusion、self+burn、三者合用；实际非零物理活动、
  时间步减半参考、动态 AMR/restart、修复账本与失败路径。平滑无修复条件下质量
  相对漂移 `<=1e-12`；周期总能量扣除核能后以初始气体能量归一化 `<=1e-6`，
  另保留 P4 引力势能归一化预算；不能以巨大背景能量掩盖引力误差。
  分裂总时间阶目标至少 1.8；如果某既有子算法只有一阶，明确显示该限制并验证其真实阶数。
- 设备安全：代表性均匀/混合层级的内存越界、过期场/退休存储、求解失败不发布。
  CPU 完整回归先通过，最终 CUDA 构建与 GPU 数值/设备检查集中进行。

## RTX 3060 Ti 性能口径

本轮按用户新指令采用基础加速验收，取代旧计划对 P6 整体完成的固定正加速前提。
正确性是硬门槛，速度是实测结果；负加速不能隐去，也不构成放松正确性的理由。
使用同一个 Release 可执行文件比较 CPU/GPU；至少小、中、大三档均匀/AMR 负载，
预热后重复至少三次，报告中位数、范围、迭代数、峰值内存以及传输/同步计数。
CPU 至少比较单线程与合理多线程，报告最快的实测 CPU 基线；同步后计时。
分开记录端到端、建层/边界、Poisson 迭代、输出开销；确认真实 GPU 核执行，
不以微内核加速替代端到端结果，不把 CPU 回退算成 GPU 加速。

方法依据：
[Castro gravity](https://amrex-astro.github.io/Castro/docs/gravity.html) 对孤立多极的
质量支持域及直接边界求和作了区分；ARCH 的实现与验收必须由自己的数据证明。

## 最终记录

### 实现与文件归属

- `numerics/elliptic/CompositePoisson` 扩展物理边界面、非齐次 RHS 与统一面梯度；
  `numerics/multigrid/CompositeExecution` 提供共享算术任务和可替换执行接口。
  原 `HostCompositeMG` 保留文件名，内部 MG/FGMRES 已由同一流程支持两种后端。
- `physics/gravity/GravityBoundary` 管理有限域质量树；`GravityExecution` 与
  `GravityPatchView` 定义共同物理工作；`self/GravityWorkspace` 管理缓存映射和字段。
  场所有者 `SelfGravity` 保持求解、验证、发布、失效的顺序。
- **所有新增 CUDA gravity 后端文件集中于 `src/cuda/runtime/gravity/`**：
  `CudaBackendGravity.cpp` 负责借用/发布，`CudaGravityExecution.h/.cu` 只处理
  分配、kernel、归约、传输与同步。重力公式不在 CUDA 目录复制。
- 粗层复用 P2 小型求解器：每次建层生成一次有界的粗逆算子，在 CPU/GPU 应用同一系数。
  没有新增全域 KLU/cuDSS、FFT/Green FFT 或配置旋钮；已有稀疏燃烧 provider 保留。
- Driver 仅接入已有阶段服务；较细的几何缓存、物理执行和计时分别归入已有辅助模块。
  初始场也通过选定后端求解。势/力只在输出要求时下载，检查点保存 v6 物理身份并在恢复时重求解。

### 独立误差与科学适用性

- 三档非齐次 Dirichlet 制造解：均匀和混合网格，势阶至少 2.88、面力至少 2.06、
  物理边界力至少 2.35，均高于 1.8。周期原有 1D–3D 空间预算保留。
- 偏心非球源树边界与显式点质量和对照：立方与矩形域相对误差最大约 `2.0e-5`；
  半开角误差不超过 `5.3e-7`，同开角单极误差约 `2.9e-3–4.1e-3`。
  开角/矩阶敏感性和直接求和核对索引，未用另一份相同树代码充当独立参考。
- 三维高斯源 16³/32³/64³：势 RMS 相对误差 `6.73e-3/1.64e-3/4.05e-4`，
  力 `3.76e-2/9.33e-3/2.33e-3`，约二阶。背景质量始终保留。
- 域扩展使用更宽的同一高斯源和相同 `dx`，比较共同内区：误差从 `9.15e-3`
  降至 `6.55e-4`。窄云已完全位于域内时，误差由离散项主导，不能用全域 RMS
  分母变化声称扩域更准；该区别在测试中显式处理。
- 热扩散–引力的三分量线性 ODE 独立参考误差约 `2.61e-4`。核能账本由终点组分
  和独立核结合能常数计算，不积分 ARCH 自己的 ENUC 当作答案。
  厘米尺度 C/O 算例有非零燃烧、非零引力与分辨出的输运效应；联合 AMR 的
  总能量扣除核能误差约 `2.4e-13`（初始气体能量归一化），且零 floor 修复。
- 平滑分裂时间阶为 **2.017/2.070**；64→128 步参考变化 `4.33e-10`，
  小于最细受测误差的 10%。保留 P4 以引力势能归一化的能量预算，避免大气体背景掩盖引力误差。

**时间阶诊断没有降低门槛。** 原 `T=1e9*(1+0.01*cos(kx))` 跨越默认
`nuclearTempMin=1e9`，存在源项开启的不光滑点；之后把阈值置于整个温度场以下，
但 `t=1e-4` 内温度仍由约 1e9 升至 2.2e9，4/8/16 步尚未进入渐近区
（阶 1.39/1.77）。其核热约为初始气体能量的 0.505，能量预算约 `4.05e-8`，
仍作为强升温守恒/稳定性结果保留，不能称为二阶通过。
最终阶数检查采用同样的真实网络、EOS、算法和误差阈值，在 `t=1e-6` 平滑区间进行；
核热仍非零（约 0.00412），同时检查更细参考。另以独立短尺度案例证明输运实际参与。

### 性能、资源与运行边界

性能使用同一 Release 程序、3060 Ti、相同残差和物理输入；先比较 CPU 1/4/8 线程，
选择其中端到端最快的实测配置，再预热并对 CPU/GPU 各重复三次。速度没有通过阈值。
`gravity_solves.tsv` 分开给出建层、源/边界、Poisson 和力更新，GPU 子项都以完成同步为界。
传输计数属于每次 prepare，含标量下载和指针上传；不包含建层元数据与显式输出字段下载，
不能把这些计数误解为整个程序的总 PCIe 流量。

`run_timings.tsv` 的输出时间包括流体 Host materialization、状态检查及 HDF5 写入；
调用前的引力字段下载在总时间内。扣除该子项只是耗时分账，不是一次真正关闭 IO 的运行。
峰值 RSS 来自独立进程资源记录；显存为整张卡的采样值，包含空闲基线，不冒称精确的单进程分配峰值。
重复结果、中位数、范围、工作量与迭代数见证据目录的性能记录。

| 负载 | 单元 | CPU 线程 | 总求解加速 | Poisson 加速 | 端到端加速 |
| --- | ---: | ---: | ---: | ---: | ---: |
| small-periodic | 64 | 8 | 0.00× | 0.00× | 0.038× |
| medium-periodic | 32768 | 4 | 1.31× | 1.30× | 0.356× |
| large-periodic | 262144 | 8 | 2.57× | 2.55× | 0.542× |
| large-isolated-amr | 233472 | 8 | 5.54× | 4.51× | 0.982× |

大周期短算例的端到端中位数为 CPU 15.19 秒、CUDA 28.02 秒；其中输出约 0.37/15.63 秒。
大孤立 AMR 的总求解约 21.16/3.82 秒，但端到端约 23.95/24.38 秒，接近持平。
这些结果明确区分求解加速和短程序负加速。四档均核对相同物理终点与求解次数。
实测峰值 Host RSS 约 1.09 GiB；显存采样基线 1425 MiB，最高 2437 MiB（整卡）。

同一 64³ 周期网格延长到 **10 个时间步**，保持初末 plot/checkpoint 输出和误差要求，
再次对 1/4/8 线程择优并各重复三次：CPU 端到端中位数 **59.71 秒**
（59.46–59.71），CUDA **43.48 秒**（43.34–43.55），即 **1.37×**；
总引力求解 **2.65×**，Poisson **2.63×**。它说明该工作量可摊薄输出成本，
不代表任意小网格或频繁输出场景都会加速。后续性能重点是输出 materialization 与小层归约/launch，
不应再复制物理公式或将整个域改接稀疏直解来追求数字。

P5–P7 是首版基本验收，不是任意 EOS/网络/边界组合和长期天体演化的认证。
当前只支持 Cartesian、2:1 二进制 AMR、有效根轴单元数为二次幂、根间距比不大于 2。
周期 1D/2D 是平移不变 Poisson 模型；三维 isolated 只含域内质量，开放流体流出后须自行处理
边界收支和外部质量的物理近似。曲线坐标、层级时间子循环、Jeans 专用细化指标、网格外质量源均未开放。
