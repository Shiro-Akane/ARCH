## 2. O7.1：补齐 JENS 诊断与 AMR 约束

### 2.1 唯一物理定义与必要控制

`JENS` 拟定义为每个 Jeans 长度包含的有效网格数，单位为 1：

$$
\lambda_J=\sqrt{\frac{\pi c_s^2}{G\rho}},\qquad
h_{\max}=\max_{d\in\mathrm{active}}h_d,\qquad
\mathrm{JENS}=N_J=\frac{\lambda_J}{h_{\max}}.
$$

这里取已接受单元的总正密度，不使用周期 Poisson 扣均值后的密度。
`c_s` 来自当前 EOS／组分对应的共享声速；不能对一般 EOS 固定套用 gamma*P/rho。
它表示该热力学闭合下的局部分辨尺度，不是新的源项、状态下限或守恒变量。

经典 Jeans 条件在等温坍缩中要求至少约四格，并非任意物理模型的充分收敛条件，
见 [Klein、Fisher、McKee 与 Truelove 的原始讨论](https://arxiv.org/pdf/astro-ph/9806330)。
本地 FLASH 的 sink refinement 使用 P/rho 的等温声速，不能直接复制到 ARCH 的一般 EOS。
ARCH 首版使用当前流体闭合提供的声速，明确记录这种差别；磁支撑、薄盘 Toomre、
辐射／燃烧松弛后的有效声速不随此诊断自动获得支持。

| 控制 | 拟定契约 |
| --- | --- |
| `refine_var=JENS` | 复用已有字段选择；与其他指标共同使用时，任一要求细化即细化，全部允许才粗化 |
| `plt_variables=...,JENS` | 只输出诊断时不改变 AMR 或推进；无 self gravity 时显式请求报适用性错误，ALL 过滤不可用派生场 |
| `jeans_cells` | 归 AmrConfig，refine_var 请求 JENS 时必填；仅输出不要求目标；有限实数且 ≥4；模板拟推荐 8，待检查后冻结，无隐式回填，也不宣称文献保证 |
| 粗化和上限处理 | 不额外暴露第二套阈值、G 或压力 floor；按父网格是否仍解析及现有层级／容量规则决定 |

只新增一个有物理意义的分辨率控制。普通 `refine_threshold/derefine_threshold`
仍是 Löhner 曲率阈值，不能兼作格数或将 JENS 再送入曲率估计。
均匀但 Jeans 未解析的状态必须能够触发细化。

### O7.3 度量、流体和输运

轴对称单元代表完整旋转环体。二维 RZ 对外统一使用完整 `2*pi` 积分量，
内部可约去公共常数，但所有模块、边界质量矩、输出与分析器必须用同一约定。

```text
V       = pi * (r_right^2 - r_left^2) * Delta_z
A_r     = 2*pi*r_face*Delta_z
A_z     = pi * (r_right^2 - r_left^2)
h_r,h_z = Delta_r, Delta_z
L Phi   = (1/r)*d_r(r*d_r Phi) + d_z^2 Phi = 4*pi*G*rho
```

这些是计划的统一约定，不是新增的另一套后端数学。
FLASH 对二维 cylindrical 的定义及有限体积说明见
[官方几何文档](https://flash.rochester.edu/site/flashcode/user_support/flash_ug_devel/node65.html)。

- [ ] 复用 `GridMetrics` 的环体积分、面面积、物理长度、体积平均 `1/r`；更新 `GridGeometryView`、
  `PhysicalPosition` 和 CUDA 度量缓存。不能仅修改 CFL 而漏掉轴向面积。
- [ ] 几何源项继续只有 `GeometricSources.h::add_geometric_source_cell` 一份；
  2D 柱坐标的第二动量是 z，第三动量保留方位速度的含义。
  轴对称不等于无旋流：离心项及角动量耦合复用 3D 柱坐标公式的无方位导数特例。
- [ ] 同步扩散梯度、矢量基旋转、黏性几何项、诊断速度分量、div／vorticity 和 AMR 指标；
  保持恒压静止态的压力通量与几何源项相消，不添加额外能量源补偿。
- [ ] 轴线标量／z 分量按偶对称，径向及方位速度按奇对称处理；没有实际方位轴，
  不再执行旧的跨半圈 donor 搜索。非零内半径是物理边界，不等同坐标轴。
- [ ] 对缺少物性闭合的 Helm 黏度／组分扩散通道保持明确能力限制；几何公式通过不代表材料模型补齐。

## 4. O8：统一用户 BC 接口，物理含义分别表达

### O8.1 一个注册入口、不同物理结果

- [ ] 在现有 `ProblemGenerator/TypedProblemGenerator` 上增加可选的边界注册／求值钩子，
  从两个公共头文件可达。复用 BoundaryAxis／Side 及现有逻辑计划，不再建立第二套边界枚举体系。
- [ ] 边界上下文包含原生与物理位置、外法向、面／ghost 身份、当前物理阶段时间、
  EOS／组分身份及必要的只读内侧状态。回调返回数据，不能直接写全域状态、访问其他块或绕过守恒提交。
- [ ] 类注册和函数注册统一落入同一描述；函数签名和可用字段在实现提交中固定，
  用两个简短算例展示，用户不需要理解 AMR 内存布局或 CUDA 指针。

| 物理对象 | 首批明确支持的用户控制 | 核心约束 |
| --- | --- | --- |
| 流体 | 保留 periodic／outflow／reflecting，增加指定入流／用户 primitive 边界 | EOS 构造能量，组分完整且有效；法向、时间和单位明确；普通 outflow 不宣称非反射特征边界 |
| 热扩散 | 指定温度、指定外法向热通量／绝热 | 与 Hydro ghost 分开表达；流体反射不自动定义导热边界 |
| 黏性／组分扩散 | 在已具备物性闭合的通道表达壁面／速度或物种通量 | 不因新 BC 接口声称已有恒星物性；总质量通量与组分通量相容 |
| 自引力 | 保留 periodic／isolated，开放逐面的 Dirichlet、Neumann 和良定线性 Robin 描述 | 算子、RHS、零空间和边界误差共同校验；复用正式 CompositePoisson 路线 |
| 混合边界 | 成对周期方向与非周期物理面的组合 | 周期面成对匹配；isolated 仍是完整质量模型，混合 Green 模型未实现时明确拒绝 |

这里的 Robin 为 `a*Phi + b*dPhi/dn = c`，不是任意非线性边界。
只接受满足所选算子良定性、有限值和单位约定的系数组合；先实现统一描述，再以独立解逐类开放。
剪切周期、通用非反射流体、任意域外质量／潮汐模型不随通用回调自动获得物理验收。

### O8.2 Poisson 兼容性、AMR 和阶段时间

- [ ] 非齐次 Neumann 使用外法向符号，并检查
  `integral_boundary(dPhi/dn dA) = 4*pi*G*integral_volume(rho dV)`；

- [ ] 边界结构／Robin 系数变化触发算子及粗层分解失效；仅边界值变化更新 RHS。

- [ ] 延续物理边界、同层、粗细及坐标接合的统一计划；轴线正则性优先于任意用户 ghost 填充，

### O9.4 30–60 分钟的资源预算

第二平台由合作者按执行细则第 5 节生产本节及 O9.1／O9.2／O9.5 的批准子集；
维护者负责冻结参考／终点／预算及科学签收。O9.3 外部对照不属于委托或必需验证。

1. 先按特征时间和收敛需求固定 `t_end`，再选主要 CPU 长轨迹约 30–60 分钟的问题规模。
   CPU/GPU 完成同一物理任务；GPU 提前完成是结果，不单独增加其终点或精度。
2. 若需要 GPU 持续运行证据，可共同放大问题，或另登记耐久性轨迹；
   不把不同工作量的墙钟相除当加速比。可选外部程序只比较同一已定义任务。
3. 长轨迹应覆盖真实反应／扩散／引力特征阶段和反复 AMR。
   不用过小 dt 或已停止演化的尾段凑时长。超预算时保存检查点并标记未完成。
4. 在中段及预先固定的采样点核对场、拓扑、收支和错误状态；
   连续运行与同后端／跨后端续算到同一终点配对。
5. 短计时交替执行多次；长轨迹优先覆盖关键物理，发现漂移、随机性或波动后再定向复测。
   不把全排列和无变化的重复运行纳入日常 CI。

## 6. O10：Grid／AMR 后续设计讨论，最低优先级

本阶段只产出选择依据。AMR 本身已经造成跨层非均匀分辨率；这里讨论的是块内物理网格映射、
各向异性／拓扑和时间推进，不是简单把一个 uniform 标志改掉。

| 方向 | 可复用部分 | 主要代价与待回答问题 |
| --- | --- | --- |
| 单调径向拉伸／逻辑到物理映射 | 保留 Morton 和逻辑细化，由 GridMetrics 统一真实面位置／体积／长度 | 当前单一 dx 假设、重构、粗细插值、椭圆算子和度量缓存需重审；拉伸本身不能保证解除极点角向限步 |
| 定向细化或角向选择性粗化 | 原指标和有限体积守恒思想 | 现有各向同性四叉／八叉层级、邻接、接合和 MG 层级会受影响，不能只改 refine 阈值 |
| 轴／极点合并单元或多块坐标图 | 共享通量和几何度量接口 | 拓扑、跨图矢量、AMR、CUDA 访存和 Poisson 都需重新设计与验证 |
| 局部时间步／层级 subcycling | 现有 stage／flux register 可作为基础 | 自引力全域场时刻、burn／diffusion 分裂、reflux 和重启一致性复杂，不能当纯网格优化 |

优先用 O9 中实际限步单元、物理长度比、RKL 阶段和 MG 迭代证据讨论径向映射与定向策略。
比较时维持同一物理分辨需求／误差，不用较粗的中心网格制造不等价提速。
O7 的 RZ 降维对轴对称问题已消除方位方向，应先衡量它解决了多少实际问题，再决定 O10 的范围。
