本轮继续沿 O 系列总表收束真实的科学缺口。现有的 RZ 方位力矩、热态闭合和几何身份沿用原实现与证据；普通柱坐标一维/三维、球坐标一维/三维、球坐标二维极平面各自保留其实际分量与量度。柱坐标二维属于 (r,z,phi) 原生 RZ，不能直接将普通点态的 m/rho 当作全部原生均值的物理点速度。

曲线坐标粘性计算复用现有的三维零 bulk Stokes 本构：tau=mu*(G+G^T-(2/3)*tr(G)*I)，mu=rho*nu。降维计算依然保留三维迹；例如，球对称 u=A*r 是无应力的各向同性伸缩，而 柱对称 u_r=A*r、u_z=0 存在非零应力。面牵引、几何连接和总能量中的机械功均来自同一份应力，没有额外的叠加耗散加热。

径向算子的密度反差检查必须采用实际的单元质量容量来计算动能。将单元中心应力与面通量分别拼接虽能得到连续 PDE 的二阶一致性，却可能破坏离散动能耗散。本轮保留了三格反例，采用同一面应变的变分导数构造几何残差，并让该面的物理速度与牵引功相配对。时间步使用该算子实际的完整绝对行界；曲率耗散项的对角贡献不能沿用 Cartesian 零行和前提下的半行界。

CUDA已实际重编译并运行上述受影响内核owner；公开CUDA生产库尚未为本节点重建，待剩余共享数学冻结后统一进行，旧ELF不代签新源码。完整Native RZ径/轴张量、FV粗细面及非线性RKL、连续引力总能量和其余O9出口保持独立待验。[处理后证据与委派摘要](../../validation/gravity/results/release-closure-20261007/shared-curved-stokes-20261009-summary.json)保存实际身份、原失败和有限结论。

### 1.1 gravity_G 的完整退役

原设计审计的数据路径为`PhysicalConstants.h → GravityConfig.G_const／注册默认值 → RuntimeParams → 引力执行与身份`；当前可变G成员已退役，实际求值消费共享CGS常数。
这次整理解决配置权威和维护问题；这些标量复制本身没有已证实的显著性能成本。

- [ ] 从标准参数注册、解析、校验、API 参数说明、活动输入和文档中移除 `gravity_G`，
  同时删除 `GravityConfig.G_const`。旧键在现有退役键检查中明确报错，不能掉入 custom 参数表后静默无效。
- [ ] 正式自引力 RHS、孤立边界、动力学限步、GravityBox、JeansWave 直接消费
  `arch::constants::gravity::cgs::gravitational_constant`；局部 constexpr 别名只引用它。
  不另建 GravityConstants，不提供新的 G_override、环境变量或隐藏 GUI 输入。
- [ ] 求解身份、checkpoint 和日志如需保存 G，写入由 constants 生成的只读科学身份。
  复用现有字段和版本机制，保持拒绝不相容身份的检查；只有布局／语义确实改变才升级版本。
  只读记录不是第二个可调默认值，不能反向覆盖当前 constants。
- [ ] `UniformGravity` 物理适配器不再提供任意 G 的生产入口。任意系数制造解通过现有
  elliptic／multigrid 的 RHS 测试接口构造，保留通用 Poisson 数学的可复用性。
- [ ] 活动验证中 `radial_1d.py` 的 `gravity_G=1e-20` 不能简单删行：
  用实际 CGS 的密度、长度、温度重建同一无量纲引力强度 `G*rho*L^2/c_s^2` 和
  特征时间比，再用独立 Gauss／势解核对。保留低幅引力不被数值兜底吞掉的覆盖。
- [ ] 更新由 ARCH 独立执行的活动验证输入与分析所用 G；历史输入、计时和原始输出保持原样。
  位于外部对照目录的 ARCH 运行输入也须使用新契约，迁移验收不需要运行外部程序。
  可选 FLASH 对照中的常数差异另见 O9.3，不构成 O7.0 的外部依赖。
- [ ] 将当前用 `gravity_G=exp(-17)` 的语法测试移到已有 `gravity_g_x/y/z`；
  后续表达式字段只剩六个网格边界和三个外部加速度，共九项，`pi` 与 `exp(number)` 始终同范围。

## 2. O7.1：JENS 诊断与 AMR 约束

实现已经移交；下文保留原设计和验收要求。当前维护者复核已有接线和证据，只修复实际缺陷；文件映射按其基线阅读。

### 2.1 唯一物理定义与必要控制

`JENS` 拟定义为每个 Jeans 长度包含的有效网格数，单位为 1：

$$
\lambda_J=\sqrt{\frac{\pi c_s^2}{G\rho}},\qquad
h_{\max}=\max_{d\in\mathrm{active}}h_d,\qquad
\mathrm{JENS}=N_J=\frac{\lambda_J}{h_{\max}}.
$$

这里取已接受单元的总正密度，不使用周期 Poisson 扣均值后的密度。
`c_s` 来自当前 EOS／组分对应的共享声速；不能对一般 EOS 固定套用 gamma*P/rho。
它表示该热力学闭合下的局部分辨尺度，不是新的源项、状态下限或守恒变量。

经典 Jeans 条件在等温坍缩中要求至少约四格，并非任意物理模型的充分收敛条件，
见 [Klein、Fisher、McKee 与 Truelove 的原始讨论](https://arxiv.org/pdf/astro-ph/9806330)。
本地 FLASH 的 sink refinement 使用 P/rho 的等温声速，不能直接复制到 ARCH 的一般 EOS。
ARCH 首版使用当前流体闭合提供的声速，明确记录这种差别；磁支撑、薄盘 Toomre、
辐射／燃烧松弛后的有效声速不随此诊断自动获得支持。

| 控制 | 拟定契约 |
| --- | --- |
| `refine_var=JENS` | 复用已有字段选择；与其他指标共同使用时，任一要求细化即细化，全部允许才粗化 |
| `plt_variables=...,JENS` | 只输出诊断时不改变 AMR 或推进；无 self gravity 时显式请求报适用性错误，ALL 过滤不可用派生场 |
| `jeans_cells` | 归 AmrConfig，refine_var 请求 JENS 时必填；仅输出不要求目标；有限实数且 ≥4；模板拟推荐 8，待检查后冻结，无隐式回填，也不宣称文献保证 |
| 粗化和上限处理 | 不额外暴露第二套阈值、G 或压力 floor；按父网格是否仍解析及现有层级／容量规则决定 |

只新增一个有物理意义的分辨率控制。普通 `refine_threshold/derefine_threshold`
仍是 Löhner 曲率阈值，不能兼作格数或将 JENS 再送入曲率估计。
均匀但 Jeans 未解析的状态必须能够触发细化。

### O7.3 度量、流体和输运

轴对称单元代表完整旋转环体。二维 RZ 对外统一使用完整 `2*pi` 积分量，
内部可约去公共常数，但所有模块、边界质量矩、输出与分析器必须用同一约定。

```text
V       = pi * (r_right^2 - r_left^2) * Delta_z
A_r     = 2*pi*r_face*Delta_z
A_z     = pi * (r_right^2 - r_left^2)
h_r,h_z = Delta_r, Delta_z
L Phi   = (1/r)*d_r(r*d_r Phi) + d_z^2 Phi = 4*pi*G*rho
```

这些是计划的统一约定，不是新增的另一套后端数学。
FLASH 对二维 cylindrical 的定义及有限体积说明见
[官方几何文档](https://flash.rochester.edu/site/flashcode/user_support/flash_ug_devel/node65.html)。

### O8.1 独立命名的注册入口、不同物理结果

- [x] 在现有 `ProblemGenerator` 注册身份上绑定同目录边界回调，

| 物理对象 | 首批明确支持的用户控制 | 核心约束 |
| --- | --- | --- |
| 流体 | 保留 periodic／outflow／reflecting，增加指定入流／用户 primitive 边界 | EOS 构造能量，组分完整且有效；法向、时间和单位明确；普通 outflow 不宣称非反射特征边界 |

- [x] 非齐次 Neumann 使用外法向符号，并检查

- [x] 延续物理边界、同层、粗细及坐标接合的统一计划；轴线正则性优先于任意用户 ghost 填充，

- [x] 在已有诊断输出器接入边界质量、动量、热／核素通量及能量收支。

## 6. O10：Grid／AMR 后续设计讨论，最低优先级

本阶段只产出选择依据。AMR 本身已经造成跨层非均匀分辨率；这里讨论的是块内物理网格映射、
各向异性／拓扑和时间推进，不是简单把一个 uniform 标志改掉。

| 方向 | 可复用部分 | 主要代价与待回答问题 |
| --- | --- | --- |
| 单调径向拉伸／逻辑到物理映射 | 保留 Morton 和逻辑细化，由 GridMetrics 统一真实面位置／体积／长度 | 当前单一 dx 假设、重构、粗细插值、椭圆算子和度量缓存需重审；拉伸本身不能保证解除极点角向限步 |
| 定向细化或角向选择性粗化 | 原指标和有限体积守恒思想 | 现有各向同性四叉／八叉层级、邻接、接合和 MG 层级会受影响，不能只改 refine 阈值 |
| 轴／极点合并单元或多块坐标图 | 共享通量和几何度量接口 | 拓扑、跨图矢量、AMR、CUDA 访存和 Poisson 都需重新设计与验证 |
| 局部时间步／层级 subcycling | 现有 stage／flux register 可作为基础 | 自引力全域场时刻、burn／diffusion 分裂、reflux 和重启一致性复杂，不能当纯网格优化 |

优先用 O9 中实际限步单元、物理长度比、RKL 阶段和 MG 迭代证据讨论径向映射与定向策略。
比较时维持同一物理分辨需求／误差，不用较粗的中心网格制造不等价提速。
O7 的 RZ 降维对轴对称问题已消除方位方向，应先衡量它解决了多少实际问题，再决定 O10 的范围。
