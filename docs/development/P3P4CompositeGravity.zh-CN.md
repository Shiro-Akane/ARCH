# P3/P4：CPU composite AMR 与基础自引力闭环

状态：算法与预算实施前冻结，CPU 实现/专项验证、完整回归和 CUDA 兼容检查已通过，完成本次基本验收；2026-09-22；基线 `3c73cca2`（P2 已推送）。
授权：完成 P3/P4 的基本验收后推送 `physics/selfgravity`；不进入 P5 孤立边界或 P6 GPU 求解。

## 数值与支持边界

本次生产目标是 CPU、Cartesian、全周期引力/流体边界、1D/2D/3D、Euler/RK2/RK3、
多块和 2:1 动态 AMR、重启。初次能力开放以无燃烧/扩散的流体—引力闭环为范围；
复杂分裂耦合与非周期物理引力边界另行验收。P2 给定势数学接口继续保留。
不将 patch 独立解、全域展开到最细均匀网格或只交换一次势称为 composite 求解。

AMR adapter 只导出有效叶子 cell 的逻辑坐标、层级、几何与 owner 映射；
数值层拥有独立辅助层，不借用退休父块，也不把势塞入 fluid packing。
复合算子为共享子面的负梯度散度；每个粗细子面只计算一次通量，两侧以相反符号计入，
粗面使用其细子面面积积分。相容性和规范使用叶子体积加权均值，最终残差用同一原算子重算。

同层面使用二点法向差分。粗细界面用局部二次多项式再现约束修正二点梯度，
包含切向偏移；禁止把错位中心间的二点差分直接当作二阶法向力。
几何系数只在拓扑重建时生成，apply 只遍历局部面 stencil，不建立全域密集矩阵。
该算子不宣称体积内积下对称；不使用 CG。MG 用独立几何粗化、体积 restriction、
分片常数的带符号 correction prolongation、固定 Jacobi 平滑；以 restart=20 的 FGMRES 外循环稳健收敛。
均匀粗层复用 P2 的既有求解器；接口、状态、失败规则沿用 P2，不另写 sparse provider。

## 阶段、能量与生命周期

在 P1 的全域 Hydro preparation 中从真实 input slot 收集密度，按每个 block 的
handle、topology epoch、storage identity 和 state version 记录输入。每个 RK 阶段
准备一次场，patch 只读已完成结果；求解失败不发布，不以旧场继续推进。
输出、CFL、regrid/reflux 后和 restart 的接受态字段由 Driver 显式准备，IO 不隐式求解。
首版从零初值重建，避免 warm start 使 restart 轨迹依赖未保存缓存。

动量采用阶段密度乘以兼容的 cell acceleration；能量使用实际 Riemann 质量通量
与相同域面加速度的功，按已有 RK 权重组合。外部常加速度源项行为不变。
此基础方案不声称机器精度的气体加引力总能量守恒：非对称粗细算子、空间离散、
有限时间积分和 AMR reflux/重网格会产生误差，必须分别报告并随分辨率/时间步检查。
不得用全域能量平移、密度 floor 或放宽测试掩盖误差。
若预设预算无法通过，修正离散或收紧实际开放范围，不能将未通过组合登记为能力。

沿用 `gravity_G`、`gravity_type`；仅新增引力 BC、rtol、atol、最大循环这四个有真实消费者的键，
均属于 GravityConfig，GUI 高级显示由其负责人处理。atol 的零默认值代表相对精度主导；
精确零源从零初值立即接受，不给低密度引力加入固定 CGS 残差下限。
平滑参数/插值选择/粗层阈值保持算法内部常量。重力步长限制复用现有 CFL 控制：
`dt_g=min(cfl/sqrt(4*pi*G*rho_max), cfl*sqrt(h_a/abs(g_a)))`，仅对非零加速度取后一项。
Cartesian cell 的能量增量为每轴 `dt/2*(F_rho,lo*g_lo+F_rho,hi*g_hi)`。

P3 的点值制造源用于三档收敛；另保留 1D 体积平均正弦源的 Gauss-law 绝对误差见证：
该源在均匀网格给出几乎精确的面力，不能用舍入量级误差比估计阶数。
时间阶测试固定 32 格 PCM 空间算子，CFL=0.8/0.4/0.2，对独立细步 RK3（CFL=0.00625）
作比较，同时检查更细参考的一致性；解析 Jeans 波仍用 MUSCL 检验完整时空误差。

## 预先固定的基本验收

1. P3：周期制造解，在 1D/2D/3D 的均匀、多块和固定混合层级上至少三档网格。
   势及全部面/粗细界面力的体积或面积 RMS 阶数目标 ≥1.8；报告界面与全域误差，不能互相遮盖。
   rtol=1e-10、atol=0、最多 200 个外迭代；最终原算子 residual 必须达标。
   常数零空间、粗细通量相消、restriction 体积守恒、坏拓扑、非有限和非收敛拒绝均需覆盖。
2. P4：周期 Jeans 稳定线性模，以连续解析频率 `omega^2=c_s^2*k^2-4*pi*G*rho0`
   检查初始场、力方向及早期波形。64 根层格的主验证相对扰动 RMS 误差 ≤2%；
   至少三档空间网格以及 Euler/RK2/RK3 时间误差的独立细步参考，目标阶数分别 ≥0.9/1.8/2.7。
3. 能量单独计算 `sum(V*(E+rho*phi/2))`，质量相对漂移 ≤1e-12；
   平滑测试的总能量误差以初始引力势能幅度归一化，64 格目标 ≤1%。
   均匀网格净自力归一化 ≤1e-11；AMR 初步预算 ≤2e-3 且细化后下降。
   记录 hydrodynamic repair budget；无修复的平滑解才用于本项。
4. 动态 refine/coarsen/no-change、场过期拒绝、求解失败不发布、reflux 后重算、
   连续与 checkpoint 恢复比较必须覆盖。场不写入 checkpoint，恢复后由密度重建。
   引力配置进入检查点物理兼容指纹；改变 G/BC/精度时明确拒绝不兼容恢复。
5. 只开放通过的 CPU 组合；CUDA self 明确拒绝。CPU 完整回归及受影响 CUDA 构建后置集中执行。
   GUI 的配置检查仍不等于运行就绪；元数据/能力说明同步更新，不改本地 studio 工作。

## 已执行的基本验收与边界

1. 1D/2D/3D，各 uniform/refined、16/32/64 根层格，共 18 次独立制造解。
   最细 mixed 3D 有 491,520 个叶子 cell，17 次外迭代；势/全部面力/界面力末档阶数
   分别 2.0002/2.0357/2.0207。非对称密度的归一化净自力从 2.61e-4、6.80e-5 降至 1.71e-5。
   CPU O2 单进程完整该组测试约 12.1 s，峰值 RSS 705 MiB；这是当前实现的资源观测，
   不是 GPU 性能，也不是普适内存上限。尚未做专门线程并行/缓存布局优化。
2. 64 格 MUSCL Jeans 波在 t=0.1 s 的扰动 RMS 相对误差 0.1596%；
   32/64/128 格分别 0.6569%/0.1596%/0.04652%。有限振幅带来非线性误差，
   不把末档偏离纯二阶一概归于 Poisson。单独算子仍通过二阶标准。
3. PCM 固定空间算子的时间阶：Euler 1.023/1.012，RK2 2.004/2.002，RK3 3.004/3.002。
   独立细步参考再减半的变化小于所有被比较时间误差的 1%。
   **1% 能量预算对应 64 格标准算例**：Euler/RK2/RK3 分别约
   0.4875%/0.00000120%/0.000642%。32 格、CFL=0.8、t=0.3 的 Euler 时间阶探针
   则有约 10.3% 势能归一化能量误差，随 dt 缩小；不能把该粗步探针宣称为能量合格运行。
4. 动态 AMR：64/128 格，phase=pi/4，refine=2e-5*(64/N)^2，
   derefine=5e-6*(64/N)^2，t=0.4 s；分别观察到 6/23 次加密和 4/20 次粗化，
   同时含 no-change 与混合层级输出。最初试用的 derefine=4e-6 在 64 格不足以触发
   整个 sibling 组粗化，因此改用能实际覆盖该分支的输入阈值，未改 AMR 算法或误差门槛。
   两档质量相对漂移 2.80e-14/5.65e-14；能量归一化误差 8.55e-5/4.31e-5；
   所有采样时刻的最大净自力误差 8.96e-8/6.79e-9，随细化下降。
5. 实际 2D/3D 多块与混合层级 Driver 做两个完整 RK3 步，检验原生映射、输出、残差、质量和能量。
   另用三轴乘积密度场检验真实 native 布局下全部非零加速度分量，避免仅沿 x 的波遗漏 y/z 映射。
   **长时间动态 AMR 演化的本轮物理验证是 1D**；3D 的完整二阶证据是复合算子制造解。
   这属于基本验收，不代表长时 3D 塌缩、湍流、燃烧或辐射耦合均已验收。
6. 动态 AMR 连续/重启末态 14 个 checkpoint dataset 逐位一致；改变 G、rtol、atol 或
   最大迭代次数均明确拒绝恢复。场没有保存到 checkpoint，全部由恢复的密度冷启动重建。
   检查点格式更新为 v6；不兼容旧 v5 文件。阶段失效、错误 slot/非首块版本/布局、
   坏密度、非收敛与旧 topology 拒绝由生命周期测试覆盖；新增嵌套层级与低密度尺度检查。

## 能量公式与时间阶段说明

在均匀 Cartesian 周期网格，`g_face=-(phi_R-phi_L)/h`。
质量方程的半离散变化满足
`dW/dt=sum(phi_i*d(rho_i)/dt*V_i)=sum(F_rho*(phi_R-phi_L)*A)`，
其中 `W=sum(rho*phi*V/2)`，对称离散 Poisson 和一致的零均值规范使另一个半项相同。
本次面通量功的全域和正好为该式的负值。因此均匀网格在半离散层次有相容的能量交换，
时间积分有限步长仍有误差。每个 Euler/RK 子步先按其真实密度求解，再由既有权重组合状态；
这让时间中心化来自 RK，而不是在旧势上重复施加固定源。

粗细界面采用二次再现面梯度，且粗/细 hydro 面通量在最终 reflux 前未必相同，
不能直接套用上述对称两点证明。当前采用明确的能量误差预算与网格收敛，
没有事后将全域能量误差回填各 cell 的操作。后续严格保守能量扩展若加入，
必须重新给出 composite 算子、质量通量、势时间导数与 AMR 校正的离散证明。


这些波的引力势能幅度远小于背景气体能量，因而能量归一化诊断会放大舍入累计；
例如 uniform RK3 三档能量误差不单调（3.02e-6/6.42e-6/1.34e-5），但远低于 1% 预算。
不能据此宣称机器精度的总能量守恒。当前实际演化解析验收以 IdealGas/HLLC 为主，
Euler/RK2/RK3 共用同一源项实现；其他 EOS/flux 继续使用既有编译/回归路线，
具体研究场景仍需自己的物理验收。
