## 共享 owner 实现
AmrFluxPlan 的 topology builder 显式携带 GeometrySemantics：
fine/coarse 注册面积与 reflux A/V 取同一 RZ view，默认 Existing chart 保留。
FluxRegister::BuildRefluxPlan 的实际 HasData 路径也携带该 chart；
shared AmrFluxMath 的符号、stage weight、conservative/species 更新没有变更。

topology 缓存记录 chart/native Grid snapshots，内部 fingerprint contract 升级2；
不改变配置 API、生产 Plotfile 或 checkpoint 格式版本。
原生几何与 chart 独立于 epoch，改变后不能复用旧物理权重。
cached reflux 用完整 topology fingerprint 关联，不只比较 epoch。
每个 patch 注册校验 indexed native source，map lookup，不扫描全树；
全计划查询/reflux 才检查一次所有 bindings。
直接旧 topology / 新 native source 组合明确拒绝。

累计 flux 另携带 producer topology fingerprint。
经过完整 registration 输入检查、非zero stage才绑定；
wrong chart/new geometry 不能消费旧累计值，明确要求 Clear。
Clear/Resize 为 scheduler barrier，不允许与 registration 并发。
新增身份锁仅保护绑定/验证；原来原子 flux accumulation 的数学保持。
未带 producer identity 的底层手工 legacy fixture API 仍兼容；
显式 RZ 有实际 reflux operation 时要求 producer identity。
无 coarse-fine interface 的 uniform RZ empty reflux 保持 no-op。
