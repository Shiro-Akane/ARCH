## 1. 目标范围和分批开放

| 原生 Grid | 目标物理含义 | 首次生产验证阶段 |
|---|---|---|
| spherical 1D：`r` | 球对称三维物质，包含中心的有限质量模型 | P10 |
| cylindrical 1D：`r` | 沿轴无限延伸的柱对称物质，质量按单位长度计算 | P10 |
| cylindrical/spherical 2D：`r,phi` | 保持现有极坐标平面语义；Poisson 对应沿垂直方向平移不变的三维物质 | P11，避开原点；P12 补齐原点 |
| cylindrical 3D：`r,z,phi` | 三维有限域物质 | P11，避开轴线；P12 补齐轴线 |
| spherical 3D：`r,theta,phi` | 三维有限域物质 | P11，避开原点/极点；P12 补齐完整坐标奇点 |

二维 `spherical` 不改成 `r,theta`，二维 `cylindrical` 不改成 `r,z`。
真正的二维轴对称恒星/柱对称模拟、薄盘的三维引力都需要独立物理契约，不通过更名或默认为本轮开启。
P11 的避奇点域只声明实际计算域及边界，不冒充完整球体；部分方位角周期扇区的镜像质量也不默认支持。

首批曲线模型使用完整方位角周期（适用时）与物理径向/轴向边界。径向不能当作普通周期长度轴。
Cartesian 的现有 `periodic`/`isolated` 行为保持。曲线 `isolated` 表示其对称性下无额外域外物质：
球对称/三维模型使用有限质量势；无限柱/二维极坐标模型使用单位长度质量与对数势，并固定势的参考常数，
不声称无穷远势为零。低维柱/平面模型以固定势规范下的单位长度收支和边界项验收，
不套用三维有限质量系统的无穷远总势能预算。原点外有空洞的输入，首批表示空洞内无额外质量；
外加中心质量不在本轮范围。

## 2. 唯一实现和复用约束

1. 保留一个 `SelfGravity`、一个阶段 prepare/publish/invalidate 流程和现有 `IGravityPolicy` 调用边界。
   不创建 `SphericalSelfGravity`、`CylindricalSelfGravity` 或坐标专属 Driver 阶段。
2. 保留一个 `GeometricSources` 数学实现。几何源项描述曲线坐标流体方程；引力仍按局部正交分量
   `rho*g` 加入，不把 Poisson 的径向/角向项再作为一套流体源项叠加。
3. 势的梯度、几何系数、动量与能量公式由公共 C++ 数学拥有。CUDA 只处理存储、遍历、归约和同步，
   不增加球/柱坐标专属公式内核。现有行运算、梯度任务、FGMRES、V-cycle、归约和发布机制优先复用。
4. `GridMetrics` 是体积、面积、物理长度及所需几何矩的唯一公式来源。椭圆层可以缓存其结果，
   不复制 Hydro/扩散度量公式；流体向量传递不拿来直接传递 MG 标量。
5. 保留现有燃烧–扩散–流体分裂顺序；燃烧、扩散、reflux、regrid 后必须使用正确版本的密度与场。
6. 不新增用户平滑步数、轴线 epsilon、坐标专属 G、CUDA 迭代参数或数值方案开关。
   继续使用 GravityConfig 的 G、边界、残差和迭代上限；所有新增实现先在内部验证。
7. 当前网格的 `cm` 与 `rad` 不能直接比较 spacing ratio。改用物理长度/算子系数判断各向异性；
   不把过去 Cartesian 的 `spacing ratio <= 2` 文本原样扩展到角坐标。沿用根轴二次幂及 2:1 AMR
   的已验收拓扑边界，本轮不顺带开放任意 refinement ratio。

## 3. 接口和离散契约

### 3.1 网格、算子和边界

- AMR adapter 继续提供 active leaf、逻辑索引、block handle 和 native storage offset；增加明确的几何身份。
  拓扑连接仍使用逻辑坐标，物理度量从共用 Grid 几何生成；同一层的单元不再假定等物理体积。
- 通用椭圆网格描述包含维度、几何种类、根轴范围/坐标步长和逻辑尺寸。物理对称性由已验证的
  geometry/dimension 组合解析，不在多个配置结构里重复保存可独立修改的开关。
- 继续采用 `A=-div(grad)`：`(A Phi)_i = -sum_f A_f*(grad Phi dot n)_f / V_i`。
  源密度为单元体积平均；势的采样位置、面梯度/面势的点值或平均语义在 P8 冻结。
  保留当前 cell-centered 势约定，任何改为体积平均未知量的方案须另列数值变更，不能隐含在坐标重命名中。
- 切向梯度使用正确度量因子。粗细面仍只拥有一个物理通量，粗面等于子面贡献之和；
  二次拟合中的坐标距离、面积积分和边界约束随几何更新，不能只替换 `CellVolume`。
- 把现有全域单一 `BoundaryKind` 扩为内部逐面/拓扑边界描述：物理 Dirichlet/Neumann、周期接合和坐标正则性。
  `gravity_boundary` 由物理层解析为该描述；不能直接把流体 reflecting 当作引力 Neumann。
- 仅依据实际算子的零空间和边界通量兼容条件进行投影。方位角周期不触发密度均值扣除；
  带外部势边界的球/柱模型保留完整密度。常数零空间、体积权重及 gauge 由一份算子契约提供。

### 3.2 加速度、源项和做功

当前 `GravityWorkspace` 的面量含 `A_f*dx/V` 权重，并同时供动量、做功和步长消费。
曲线网格必须分开以下语义，但不分裂物理源项的所有者：

| 数据/操作 | 新契约 | 复用方式 |
|---|---|---|
| 面梯度/法向加速度 | 真正的局部正交分量，单位 `cm/s^2` | 一套共享梯度系数与面求值，CPU/CUDA 共同消费 |
| 单元加速度 | 用一致的几何重构得到局部 `g_r/g_theta/g_phi` 或对应原生分量 | 一套 `rho*g*dt` 动量数学；供输出、动量和重力步长 |
| 质量通量功权重 | 属于单元一侧，不能因为共用同一网格面而错误共用左右单元权重 | 扩展现有 sides/workspace 数组；复用 Riemann 质量通量及 flux-work 调用点 |
| 外部常加速度 | 保留现有局部正交轴解释和 cell-work 离散 | 与 self 共用动量算术；保留其已验收的能量离散选择 |

P8 先给出做功离散推导。优先考虑以实际向外质量通量和势差构造
`Delta E_i = -dt/V_i * sum_f [A_f*F_rho,out,f*(Phi_f-Phi_i)]`，
再检验其与现有面梯度功、RK 加权和 AMR reflux 的兼容关系。
该式是待验证的设计起点，不以写进计划替代离散能量推导；必须说明面势如何与梯度一致。
均匀 Cartesian 极限应还原原有公式；AMR 或数值次序变化继续满足原有科学预算，不强称逐位不变。

仅保留一个动量累加数学入口，以及有明确不同离散含义的 cell-work/flux-work 操作。
它们由已解析的物理策略选择，不同时给同一能量方程加两遍功；Host patch 循环和 CUDA batch
只是执行入口。不为坐标、EOS、燃烧开关重新声明同一套源项函数。
现有 `add_sources_on_patch` 和 `add_flux_work_on_patch` 两个调用点保留，避免破坏不同数据就绪时机。

### 3.3 多重网格与粗解

- `HostCompositeMG` 现有算法已经共用 CPU/CUDA，继续复用层次、FGMRES、V-cycle、向量和稀疏行执行。
  限制使用真实 `V_child/V_parent`；范数、兼容条件和投影统一使用同一体积权重。
- 最粗层必须来自实际曲线坐标算子。移除生产粗解对 Cartesian `HostMultigrid` 的数学依赖，
  复用已有 DenseLU 对有界小矩阵分解，并处理常数零空间；每个拓扑/算子身份建立一次。
  保留 CPU/GPU 共用粗解系数和设备本地应用，不在 V-cycle 内往返主机。
- 原有常数 prolongation 与点 Jacobi 先作为待测基线。规则域验证后，再用各向异性压力测试
  决定是否加入半粗化/线平滑；若需要，它们只归属同一 MG 算法，不为几何再建一套求解器。
- 新粗层可能出现非二次幂的小矩阵维度；先检查现有 LU 是否支持实际 active size，必要时扩展
  通用有界 LU 封装并验证，不能只修改旧 `2/4/8/16/32/64` 的调用参数。
- 不新增全域 KLU/cuDSS、FFT/Green FFT 或 AMG。原有稀疏燃烧后端继续按其职责使用。

### 3.4 物理边界和坐标奇点

- 球对称用 `M(<r)=4*pi*integral(rho*r^2 dr)`、`g_r=-G*M(<r)/r^2` 作为独立解析/积分参照，
  生产仍走共享 Poisson/MG 路径。Grid 的单位立体角体积在总质量处恢复 `4*pi`，算子内不重复乘。
- 柱对称使用单位长度质量 `lambda(<r)=2*pi*integral(rho*r dr)` 和 `g_r=-2*G*lambda(<r)/r`。
  二维极坐标的自由空间边界采用相应对数核；势的参考常数内部固定，力与做功检验 gauge 不变性。
  优先复用现有树遍历/质量矩组织，增加维度正确的核求值；直接质量积分用作小型独立参照，
  不把每个边界面遍历全部单元的主机双循环作为长期生产加速方案。
- 三维孤立边界复用现有质量矩平移和 `-G/r` 求值。树节点中心、包围尺度、单元质量矩及面采样点
  必须转换/积分到真实物理空间，不能把 `(r,theta,phi)` 当笛卡尔位置输入现有树。
  曲线单元的积分误差、开角和边界截断误差分别对独立直接积分验证。
- 原点、轴线、极点使用有限体积极限和正则性。零面积面不得通过一个任意 epsilon 变成有限通量。
  标量跨轴/跨极点连接与流体矢量基变换分别定义；现有仅翻转法向动量的普通 reflecting 不能代替它们。
- 坐标接合规则放在共用 Grid/AMR 边界计划，供 Hydro、扩散、引力及 CUDA 使用。
  首批不宣称长期恒星静水平衡精确保持；先测离散平衡误差。若需 well-balanced 重构，作为明确的
  Hydro 数值变更增加范围和验收，不能在 gravity 里补一套压力源抵消误差。

每阶段区分维护性变更与数值变更提交。纯搬迁不扩展全套科学测试；实际受影响的数值与生命周期门槛不能仅用编译代替。
阶段内的普通实现选择不要求反复审批；改变物理含义、源项公式或预算时先更新对应决策及依据。

## 6. 验证矩阵和 CI 归并

1. **独立场解**：各几何至少三档分辨率的平滑制造解，势与物理力的体积 L2 收敛目标不低于 1.8；
   原点/极点、边界和粗细界面单列误差与最大误差，不用整体 RMS 掩盖局部失败。
   一维径向体积平均多项式密度的解析面 Gauss 定律与离散通量完全相同，面力误差主要由求解残差控制；
   对此专门采用严格绝对面力预算，不对舍入误差比值强求收敛阶。非光滑质量边缘另列物理参考。
2. **几何和守恒**：总/子单元体积、粗/细面面积及通量匹配；常数场、制造线性/二次势的正确残差；
   球对称总质量、柱对称单位长度质量和二维模型单位均核对。验证改变势常数不改变力与做功。
3. **边界**：三维独立直接质量积分、径向解析积分、二维对数核参照；制造解与物理孤立边界分开。
   边界精度收紧后，变化应小于最细网格空间误差的 10%；扩域时保持原物质分布，避免同时改变问题。
4. **Hydro 与耦合**：沿用 RK 时间阶和 Cartesian 能量预算；曲线场同时检查边界质量/能量收支及引力势能。
   静水参考由独立径向平衡积分构造，密度下限/外部稀薄介质的质量计入参照；报告寄生速度随网格收敛。
   长期静水平衡、旋转/角动量和核加热案例各自冻结运行时间与预算，不以短时可运行代替。
5. **生命周期**：重网格细化/粗化、无变化、失败发布、restart、跨后端恢复、EOS/燃烧/热扩散状态更新后场身份一致。
   曲线基矢下的动量收支不能把原生分量简单求和当笛卡尔总动量；采用正确变换和物理对称量。
6. **设备与性能**：保留矩阵/数学原语、内存/竞争检查；同一 Release 程序、同物理误差预算和输入比较 CPU/GPU。
   小/中/大规则域及 AMR 至少三次正式计时，报告端到端、建层、边界、Poisson、力更新、迭代数和传输计数。
   近轴/极点负载另列。3060 Ti 小网格负加速可以如实记录，不通过降低残差或默认回 CPU 声称 CUDA 加速。

具体制造函数、分辨率、物理运行时间、绝对/相对误差和性能比较方法，在各阶段实现前写入现有 gravity
验证输入/记录；上述预算不能在看到失败后静默放宽。新增能力没有实测记录时保持规划/拒绝状态。

覆盖更新 `test_composite_poisson`、`self_gravity_lifecycle`、`self_gravity_physics` 及已有 gravity campaign；
短 CI 保留原关键锚点，以少量有区分力的代表案例替换重复项，重型维度/奇点/性能矩阵本地运行。
不按每个坐标增加 CTest 名称或 GitHub job，不删除不同物理失效模式的唯一检查来维持计数。
通用初始场优先扩展 `GravityBox` 的原生几何模式；若新问题有独立物理定义和用户用途，才新增 simulation 目录。

## 9. P8–P10 当前实施与验收记录（2026-09-23）

当前工作树已完成一维 CPU 路径的实现与数值验收，仍待提交。P8 将两个短的重力源项头合并到 `GravitySource.h`，保留一个 `SelfGravity` 和原阶段生命周期。`GravityPatchView` 分开物理面加速度与做功系数：动量仍用 `rho*g`；径向单元侧做功使用
`Delta E_i = -dt/V_i * sum_f A_f F_rho,out,f (Phi_f-Phi_i)`。面势由邻近势作共用插值，两个相邻单元消费同一个面势；Cartesian 的原有能量离散保留。Host 与 CUDA 继续调用相同数学入口，未新增用户物理参数。

P9 新增 `EllipticMesh.h` 保存几何身份和逻辑网格；`CompositePoisson` 由 `GridMetrics` 取得实际径向体积、面积，解析为逐面内部边界（中心零通量、外面 Dirichlet），并按实际算子决定常数零空间。`CompositeMultigrid` 是原 `HostCompositeMG` 的一对一更名；共用类型移入 `MultigridTypes.h`，层间限制按 `V_child/V_parent`，有界粗层 DenseLU 对实际 composite 算子分解并把逆算子上传，同一 V-cycle/FGMRES 由 Host/CUDA 执行。`HostMultigrid` 留作 Cartesian standalone 参考，不在生产 composite 粗解中调用。

P10 仅开放 CPU 一维 spherical/cylindrical、`gravity_boundary=isolated`、非负径向起点和 reflecting 内流体边界。球对称外势为 `-G*M/R`，其中 `M=4*pi*sum(rho_i*V_i)`；无限柱对称固定 `Phi(R)=0` 作为对数势规范。不引入域外质量、二维/三维曲线引力或 CUDA 径向能力。`GravityBox` 复用原算例，增加仅属该算例的均匀密度径向静水平衡参考开关；标准用户只需两个公开头。圆心处格子变窄导致的 dt 缩短按本轮明确授权暂不改动。

运行验收已通过：球/柱各三档均匀密度解析场；强引力 12 步混合 AMR、细化/无变化、封闭域质量与含势能总能量预算、检查点续算逐位一致；弱引力 40 步细化/粗化/无变化；同物理时刻三档静水寄生速度递减；`rho0=1e-12` 近真空两步无修复；无效配置拒绝。完整 `radial_1d.py` 运行 27 个输入，现有 `run_self_gravity.py --quick` 通过 32 条验收记录；`arch_self_gravity`、`arch_gravity_stage_contract`、`arch_low_density`、Cartesian 复合算子回归通过。受影响的 CUDA 重力执行/控制与 Hydro Ideal 编译通过；这只是编译兼容性，不是 P13 数值或加速验收。完整指标和复现命令见 [P8–P10 验收记录](../../validation/gravity/results/p8-p10-20260923/README.md)。

**严格椭圆门槛已关闭**：`arch_composite_poisson radial` 的球/柱、均匀/混合 AMR 共 12 组均通过三档势收敛、独立解析面 Gauss 定律和真实物理残差检查。最细圆柱混合 AMR 的原相对请求 `1e-13` 低于可达双精度舍入下限（实际残差约 `2.7e-12`，原目标约 `1.38e-12`）；经用户明确同意，将这项新增测试的相对请求定为 `3e-13`，保留势阶数、面力与真实残差验收，在 38 次迭代收敛。`composite_poisson_analytic` 与 `composite_poisson_contract` 两项 CTest 均通过；以下第 10 节记录后续 P11–P12 进度。

## 10. P11–P12 本轮实施与剩余门槛（2026-09-23–24）

P11 仍沿用一个 `SelfGravity`、一个 `CompositePoisson` 和原有 MG/FGMRES。
