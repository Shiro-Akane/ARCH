## 发布目标与判定

正式版本应做到：**当前公开声明的全部科目，在明确适用的模型、组合、后端与平台上能够正常完成计算，没有已知未解决的阻断性缺陷，并满足已有数值标准。** 这是一项可核验的发布结论，不承诺任意未知输入均无缺陷。

- 全科目包括Hydro、几何与AMR、EOS、三类扩散、反应网络／燃烧／NSE、线性求解、外部／自引力、用户边界，以及配置、输出、重启、Core API和选配Studio。按公开功能路由和公共模型验收，不能只用18类目录owner或测试数量代签。
- CPU与CUDA分别记录实际执行能力；每项公开算法／模型选项有对应证据，重要耦合组合另验。不穷举不合法的笛卡尔积；不适用组合须明确拒绝。已存在的功能不能为了赶进度自动改标experimental或移出发布目标。
- 沿用Linux／WSL2支持范围、Studio选配和已接受的近原点网格限制。一般辐射输运与Windows原生适配不凭本计划新增承诺；非法状态、错误守恒、配置误读或重启错误不能归为“网格限制”。
- CPU/GPU共享数学、物理定义、严格浮点、误差预算及性能非回归要求保持。[严格配置契约](../../development/ConfigurationContractPlan.zh-CN.md)继续禁止活动关键选项缺失或显错时静默回退，辅助默认与auto来源可追溯。
- 用户于2026-10-16要求撤出二维柱坐标，退役已按原范围签收；随后授权沿公共Grid重新引入。原生二维柱坐标的CPU／CUDA工程入口及声明的方法／EOS和必要耦合已由CYL-0至6综合签收；全科目正式发布仍须后续发布阶段，不能从坐标准入推断任意参数组合或完整Device资格。保留球坐标二维真`r,phi`及柱坐标一维／三维。
- 旧接口、脚本和重复设施无需兼容层；退役时同步当前消费者与错误拒绝。文档精简不授权悄悄改变算法、格式或配置含义。
- 模块边界纳入发布标准：公共状态／数值头不得通过宽泛helper意外导入具体物理求解器、缓存或后端资源owner；几何独立，必要守恒耦合通过明确接口／组合层完成。关闭可选模块的路径仍须可运行，未知活动路由明确拒绝。必要边界附件、共享数值view与配置聚合允许存在，但暂态生命周期须显式；前声明收窄不冒称所有权已迁移。使用现有架构审计及针对性负对照验收，不禁止一切跨模块引用，不为低收益归属建议无限延长发布。
- 阻断项包括：正确性／数据完整性缺陷、公开路径不能完成、必要数值证据缺失、配置静默回退、产物不能按说明使用。非阻断性能建议与文字润色不无限扩展发布范围。

### 实现方向与必要差异

采用现有三维柱坐标`(r,z,phi)`的轴对称约化：计算轴为`(r,z)`，`∂phi=0`；沿用三动量`(rho*u_r,rho*u_z,rho*u_phi)`，保留旋转。二维`(r,phi)`作为共同数值流程和成本参照，三维柱坐标作为基底、连接项与约化数学参照，按原生三分量及一致phi测度投影，不以Cartesian矢量的全环平均代替。沿用已有`Grid`、`CoordinateLayout::CylindricalRZPhi`和公共曲线坐标文件，不另造RZ Grid、状态、重构／通量／粘性求解器、保存点或控制器。

| 项目 | 已冻结的数学／存储约定 |
| --- | --- |
| 轴与分量 | `x1=r`、`x2=z`，均为长度；未活动phi方向没有空间导数，`mom_w`仍表示方位动量密度。继承当前三维柱坐标的正方位与基底符号；涡量等叉乘量需核对顺序，不能仅交换数组索引 |
| 有限体积测度 | 令`Q=(rR-rL)*(rR+rL)/2`，内部按单位方位角使用`V=Q*dz`、`A_r=r_face*dz`、`A_z=Q`；物理间距为`dr,dz`，`<1/r>=(rR-rL)/Q`。全周物理积分显式乘`2*pi`，同一归一化贯穿质量、势能、边界矩与诊断；RZ的`V`量纲为`cm^3`，不按“二维”标成`cm^2` |
| 状态与角动量矩 | 沿用三动量PWC系数及现有Init点采样，不承诺任意解析场的精确单元平均。`W=dz*(rR-rL)*(rR²+rR*rL+rL²)/3`，派生`J=sum(mom_w*W)`，不用`r_mid*V`替代，不新增J／ell状态。角向面矩`T_r=r_face²*dz`、`T_z=W/dz`；投影／截断误差与离散守恒分开验 |
| Euler几何与离散更新 | 连续方程为`S_r=(rho*u_phi²+p)*<1/r>`、`S_z=0`、`S_phi=-rho*u_r*u_phi*<1/r>`，无几何质量／总能量源。严格角动量离散采用公共面矩：`ΔJ=-dt*sum_outward(T*F_phi)+体力矩冲量`、`Δmom_w=ΔJ/W`；乘积法则已吸收phi连接项，**不能再叠加一次S_phi**。复用共同通量／重构／遍历，仅补必要权重；按layout保留旋转，Cyl1原压力源语义保持 |
| 轴线正则性 | `r=0`为单元面，轴面径向面积为零；标量与`u_z`为偶、`u_r/u_phi`为奇。沿公共坐标拼接／边界设施处理ghost和AMR donor，不把轴当普通反射壁，不加径向epsilon，不把z方向套入phi半周映射 |
| 模块边界 | Grid与几何只提供布局、测度、正则性及几何源；Hydro调用公共通量／源项流程；引力的场、求解、边界、做功及发布仍由gravity owner管理。`GlobalDefs`／`FluidVector`不新增RZ字段；沿用现有状态与资源生命周期 |

| 可选引力 | `off`与开关对照；轴对称势`Phi=a*(r^2+z^2)`的`laplacian(Phi)=6a`及`g=(-2ar,-2az)`给规定边界独立校验，按当前算子`-laplacian`／CGS符号装配。另验孤立环形质量、Gauss收支、残差／收敛与流体能量做功；不能用残差代替场正确性，不能以rphi平面势替换轴对称物理 |

成本验收以**无引力、同维rphi对RZ**为主要对照：匹配活动单元／patch、EOS、重构／通量、积分stage、OMP、输出和固定步数；三维对照主要用于数学约化，整域墙钟不冒充同工作量二维样本。分别记录每cell-stage耗时、固定物理终点的步数／CFL、实际遍历／EOS／通量／源项计数、内存，以及编译动作与耗时。引力solve按实际RK输入和既定输出物化时序核计数，不能要求整个宏步只solve一次。

**已冻结成本报警线：**CYL-0四次重复的最大CV为2.33%。后续两个同工作量二维规模的RZ中位成本不得超过同候选rphi的2倍；本机当前绝对锚点对应上限为527.86／471.93ns每cell-stage。保留绝对锚点及同候选对照，不能靠拖慢rphi满足比例；参考有不明回归或样本不可比时暂停签收。2倍是工程报警线，CYL-2已通过所列无引力固定工作量门；不以改CFL、误差、输出或终点达标。固定步静止场之外的非均匀／物理终点、AMR、扩散另按实际工作包验。孤立引力按相同物理精度、边界和工作计数另建成本门，不能从两种不同Green函数承诺相同墙钟；其数学留在gravity owner，不侵入Grid／Hydro或复活旧RZ专用缓存、控制器。

沿用既有护栏与异常缓慢截断规则；截断记未完成，保存步数／计数与数值证据。非阻断优化假设至多两次有界尝试；正确性问题继续阻断。构建及计时窗口冻结源码／配置／输入，先定点轻编译与短例，再按实际风险扩大；不重复R3归因、旧RZ长程或每轮全仓回归。

| 发行说明与支持矩阵 | `docs/releases/`及既有功能入口 | 只写实际发行版本、可用能力与限制；功能表与验收矩阵一致，不继续堆开发代号 |
| 有长期价值的人类历史 | `docs/histroy/`（按用户指定拼写） | 提取仍有效的独有内容后归档；既有archive逐批统一，不另维护history／histroy两套新目录 |

处理方式只有保留、合并、必要历史保留、删除。先确认权威与当前消费者，再迁移内容和引用，最后退役冗余；每批检查Markdown链接／锚点、源码注释、脚本诊断、测试、CI和机器记录的路径依赖。不留下同量占位页或重定向。

**冻结JSON、原始科学结果、失败与修正记录保持原路径及字节。** 对受固定路径或不可变记录引用约束的人类材料可原位保留；不能为了统一histroy而破坏复现链。无独有信息、无活跃依赖且已被替代的过程稿可直接删除；历史区也应去冗余，不是全部永久保留。

现行标题与说明按功能命名，去掉依赖读者记忆的“v1／v2”“O阶段／旧版新版”等说法；真实协议字段、格式标识、精确命令和发行版本仅在必须说明处准确保留。沿用[现有写作规范](../../development/CommentAndDocumentationStyle.md)，不另造规范文件。英文权威及中文译文更新同一语义。

优先主题顺序：使用／配置与离线数据获取 → 科学模型及限制 → 架构／开发 → 测试／验证 → Studio／API → 历史退役。已发现的具体纠偏包括测试指南笼统建议LFS pull、普通曲线Stokes验收状态漂移、多个旧计划自称“当前入口”，逐项查来源后归一。

## 源码注释与魔法数字清理

这是与文档同等明确的发布工作包，覆盖第一方 `.cpp`、`.cu`，并延伸到承载共享数学或接口的 `.h/.hpp/.cuh`。第三方、生成物和字节冻结材料分开登记：第三方保留许可与原文；生成物优先从生成模板补说明；冻结材料在维护owner旁解释，不擅改其字节。

| 要求 | 怎么做 | 验收 |
| --- | --- | --- |
| 文件职责与Workflow | 参照`src/main.cpp`、`CudaGravityExecution.cu`、`DiffusionKernels.cuh`等现有格式：职责、输入与前置条件、真实主要步骤、输出／发布、失败路径与资源生命周期 | 读者可沿文件理解控制流、调用方和数据归属；声明头说明契约，不把声明误写成执行实现，不机械重复模板 |
| 数学就近说明 | 非显然公式附近解释符号、单位、坐标／符号约定、离散来源、假设、有效域及数值选择；适配器链接共享数学owner | 说明与真实公式、运算顺序、测度和边界一致，不为CPU/GPU各复制一份数学推导 |
| 非显然硬编码数值 | 逐类核物理常数、经验系数、容差、迭代／工作预算、索引／位掩码和设备布局参数；附近说明含义、来源、为何选此值及修改影响。适合复用的值采用有语义的命名常量 | **杜绝无含义、无依据的魔法数字**；找不到依据就列待核实并回查，不能编造推导。显然的0／1索引不堆无效注释 |

## 测试与CI的精简目标

目标是减少重复编译、无价值夹具、同一轨迹的重复执行、失效测试和过长反馈，保留所有独有科学／接口断言。**先建立旧断言—新owner—运行层的映射，再删除或合并。** 不按测试数设删除比例，也不把有效检查打包后隐藏缺项。

| 层次 | 内容与触发 | 精简原则 |
| --- | --- | --- |
| 日常快检／PR | 工具、配置／API、共享数学短检查及受影响模块；纯文档用链接／内容／示例静态核查，源码注释另核真实影响 | 优先现有CTest／Python／npm入口；工具754项约48秒可保持完整。改进纯Studio／API文档误触发，但未知路径或无法判定影响时保守选择完整常规层 |
| 模块与真实后端回归 | 相应完整物理组、独立oracle、AMR／边界／IO与restart契约、真实CUDA／受影响Studio完整链路 | 复用现有owner和受控夹具，删除重复初始化／构建／模拟；保持原组门槛、失败子case定位，按风险补必要设备诊断，不自动每次跑长程 |
| 发布资格 | 冻结版本的完整所需CPU库存、声明的CUDA路径、全部公共模型有效运行及未决科学资格，最终包／平台／托管CI | 长程、性能配对和大型组合不进每PR；在发布环境按原终点验收，跨轮复用严格匹配身份的结果。最终发布物须实际运行，不能仅靠源码树结果 |

测试代码按科学职责归属，公共夹具只抽真正重复的装配／IO／报告，独立参考不得复用生产算法制造共同错误。失效且只断言旧实现形态的测试先确认独有行为已覆盖，再退役；既有有效断言不削弱。保留RKL已经实测的职责拆分，不能为了减少文件数又合成超重单元，也不为每个参数另建编译程序。

CI继续复用现有pathgate与结果汇总，不另造调度器。精简前后比较实际cold／增量构建、测试墙钟、峰值RAM和故障定位能力；超时、空选择、必需组缺项、skip和截断明确区分，不能被过滤成PASS。源码／生成／构建／参数输入变化采用保守影响范围；已验新入口接替后删除旧轨道，不长期维护两套CI。

REL-2已给出轻图与短例的局部成本，尚不能据此缩小完整常规构建。REL-5按真实完整工作流关键路径决定测试／CI重排；完整科学出口保持，不能靠缩短原物理终点实现“提速”。

## 执行边界与最终签收

- 异常缓慢先记录达到时刻／步数、墙钟、工作计数和已有数值结果；可用既有护栏受控停止，状态记为截断／待优化。先在最小有效片段归因，再修复或转到合适资源环境完成原资格运行；没有到达原终点就不能关闭发布阻断。
- 非阻断性能假设最多两次有界尝试，收益不足即停止；科学正确性失败仍须解决。公平计时匹配编译器、FP选项、线程、输入、硬件和物理终点；局部RZ原语、整应用、构建收益分别陈述，不混入FLASH外部对比或异机旧成绩。
- 沿用conda `work`、现有资源护栏与实际机器条件；WSL约7.7GiB、GPU8GiB，按上方工作量与进程树实测选择并行度，避免持续Swap。H5批次前或增长／IO异常时看宿主E盘，约剩1GiB预警并停止大输出，不高频轮询。
- 必要EOS表／小fixture优先复用已校验本地固定资产，禁止自动反复LFS下载；发布包明确必要资产、许可、来源与用户获取方式。原始H5／checkpoint不进入文档或外部worker包。
- 文档、纯注释、测试职责调整、科学修复分别形成可验收批次。最终提交／构建身份冻结后只做必要资格检查；修复真实阻断时重新绑定受影响证据，不机械重跑全历史。
- 最终签收要求：全科目矩阵满足原标准；无未解决的公开路径阻断；完整所需验证无缺项；实际包与说明一致；文档直接可找且无已知断链；第一方源码可理解、非显然数值有解释；CI／测试有实测成本与明确职责。全部满足后才作正式发布结论。
