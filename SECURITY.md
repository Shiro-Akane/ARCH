# Reporting a security issue

Chinese translation: [SECURITY.zh-CN.md](SECURITY.zh-CN.md).

For a suspected vulnerability, use GitHub's
[private vulnerability report](https://github.com/Shiro-Akane/ARCH/security/advisories/new)
when that form is available. If private reporting is not enabled, open an
[issue](https://github.com/Shiro-Akane/ARCH/issues) asking the maintainer to enable
it, without posting vulnerability details or an exploit publicly.

Include the tested commit, affected component, expected impact and a small
reproducer. Add the relevant compiler, dependency and CPU/CUDA configuration.
Remove credentials, personal information and private research data from inputs
and logs before sharing them. Coordinate disclosure with the maintainer through
the private report.

Ordinary build problems and numerical discrepancies can be reported in
[Issues](https://github.com/Shiro-Akane/ARCH/issues) with a minimal input and the
expected result. If a crash may be exploitable, use the private route above.
