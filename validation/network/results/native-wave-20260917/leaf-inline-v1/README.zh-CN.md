## 实测结果

仅把私有 generated `JacobianSink::set` 的 `ARCH_HEAVY_INLINE` 改为 `ARCH_INLINE`。
函数体、运算顺序、网络/CSR/表数据和 strict-FP 不变。原测试的 RHS、Jacobian、能量/温度导数一起求值；
rho=1e7、T=3e9，5 次预热，5 组 × 20 次调用，每组按原版/候选/候选/原版运行。

200 原版约 0.91–0.92 ms、候选约 0.96–0.97 ms。不是 CPU8 与 GPU 的应用加速比。

原 `2e-10 * max(1, abs(cpu))` CPU/GPU 预算全部通过。
