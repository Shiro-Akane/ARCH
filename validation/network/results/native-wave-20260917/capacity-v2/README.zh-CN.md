# native-wave v4：容量数值门槛通过

2026-09-17：12/12 harness、24 条存储轨迹、96 对 CPU/GPU 宏步完整通过。
这是 IdealGas、NSE=false 的专用核反应测试，不是完整 Helm 应用或正式性能验收。

## 固定协议及数值

150/200 核素 × BE_NR/BD/ROS4 × pool 8/32；每组依次使用 32、33 个非均匀单元，
各四步至 `1e-10`。rho=`1e7`、T=`3e9`、cv=`1e8`、rtol=`1e-7`，初始 C12/O16 各 0.5。
相对首轮仅将单 harness 墙钟限制 1,800→7,200 秒；物理时长、步数和预算不变。
[首轮超时](../capacity-v1/README.zh-CN.md) 独立保留，不混入本轮通过记录。

场误差为 `abs(CPU-GPU)/max(1,abs(CPU))`，预算 `2e-10`；limiter 预算 `2e-8`。
下列指标在两个 pool 下相同。尝试／拒绝数是 CPU 参考统计，不代表 GPU 工作量相同。
