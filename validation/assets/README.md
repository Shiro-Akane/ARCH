# Shared validation assets

This directory has no data payload at present. Existing assets already have
specific owners:

- [EOS tables](../../EOS_toolkit/README.md): production runtime datasets.
- [Test fixtures](../../tests/fixtures/README.md): recorded reference values and
  manufactured systems used by regression tests.
- Module `inputs/` directories: canonical parameter files and generation recipes.
- Module `results/` directories: identified measurements, figures and run records,
  reached through the [Validation index](../README.md).

Use this directory for a future presentation asset shared by several validation
pages, with its source and reproduction method recorded. Keep module-specific
data with its owner and link existing assets rather than copying them here.
