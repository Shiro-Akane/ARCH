## 保留的实现与适用范围

- `eos_coulomb_mult` 默认 1，取有限 `[0,1]`，一致缩放 Helmholtz 离子 Coulomb 项及其导数，保留原非正压／能量保护。它不是电子补齐开关，非默认值不适用于其他 EOS。
- `hll_wave_speed` 默认 `roe`，可选 `davis`，统一作用于 HLL、HLLC 及其支持的 PCM／MUSCL／PPM 重构。面状态继续调用完整 EOS，Davis 仅用端点声学界限。其他通量具有自身特征谱，拒绝该非默认选项。
- `dt_max` 默认 -1，不额外限步；否则为不小于 `dt_min` 的有限秒数，在保存步长控制历史与输出对齐前施加。不能放宽 CFL 或燃烧稳定性限制。
- 参数目录为 95 项，归属既有 EOS／Runtime；Core 不创建 Advanced 分组。格式 6 检查点的状态控制身份为修订 2、18 项，纳入三个新控制。旧身份不静默补齐。
- 五种通量复用 `FluxSweep.h` 的 CPU 遍历、阶段均值准备与守恒限制；CUDA 绑定同一只读视图和数学叶函数。旧接口兼容分支与重复强制内联宏拼写已经清除。
- screen5 的固定核素对因子与热力学状态分开，允许字面量常量折叠；原筛选公式和分支保留。1400 个值／温度导数对照与原式无差异。短补偿叶允许内联，求和顺序及显式 FMA 不改。实测负收益的 Hermite 零／单位权重分支已经撤除。

两次 Strang 燃烧、热耦合 ODE、严格 EOS 反解、AMR 判据和 CFL 上界均未删除或放松；不按算例名称设置捷径。

非同态面的端点复用还要求传入 EOS 的内能与均值查询完全相同。初次历史场验收发现
Sod 能量归一 Linf 为 2.3044e-8，略超原 2.02e-8；方向恢复的舍入差未进入缓存键。
修正后 Sod 全部检查点场逐位一致，一 ulp 内能变化必须重新查询的控制加入共用叶测试。
未放宽原门槛，相关旧计时保存到 `earlier/`，最终源码另行复测。

## 面 EOS 近似的否决

在实现前固定：质量／总能积分相对差不超过 1e-3，密度／压强／温度体积加权 L1 不超过 1%，主要核素总量差不超过 1%；同时检查同一终点、有限正值、组分归一与零修复。此门槛比较候选与 ARCH 默认方案，不等于与 FLASH 的共同科学预算。

| --- | ---: | --- |
| 冻结 Gamma_e／Gamma_1 | 1.882% | 未通过 |
| 重构压力，保留原守恒面能量 | 1.578% | 未通过 |

## O3、LTO 与 fast-math

原 Release 主体已经使用 `-O3 -march=native`，但 dispatch 目标另以 `-O1` 和
`-fno-inline-functions-called-once` 覆盖。实际链接原已启用 `-flto=auto` 和 mold；不存在
“尚未开启 LTO”的额外收益。当前移除 dispatch 的低优化覆盖，保留严格浮点合同。

下表使用**同一中间源码**、相同细网格输入和 Davis 波速，各自三次串行全进程墙钟；
该中间源码仍有后来因负收益撤除的插值权重分支，因此不与最终源码混作同一组排名。

| 编译配置 | 中位数 s | 相对 O1 的用时减少 |
| --- | ---: | ---: |
| O1 dispatch + native + LTO | 27.328 | — |
| O3 dispatch + native + LTO | 26.876 | 1.65% |
| O3 + LTO + `-fno-math-errno` | 26.323 | 3.68% |

收益有限，不能将其外推为所有模块的固定加速。ARCH 没有依赖数学库 errno，采用较窄的
`-fno-math-errno` 后仍保留显式定义域／有限数检查、非正规数、补偿算术与禁止隐式收缩。
[GCC 编译选项说明](https://gcc.gnu.org/onlinedocs/gcc-13.1.0/gcc/Optimize-Options.html)
区分此单项与 `-ffast-math` 打包启用的更强假设。

独立运行时输入探针中，严格 O3 和 no-math-errno 都给出补偿和 1、NaN 非有限、
`1e-310/2≈5e-311`；全局 fast-math 分别给出 0、NaN 被判为有限、极小数清零。
生产补偿头本身拒绝 fast-math 构建。故不启用 `-ffast-math`／`-Ofast`，不删除该保护。

## 剩余差距的范围

当前默认、Davis 与上一轮的逐次重网格步号／叶数历程相同，累计真实叶单元宏步
均为 4,337,664；原 FLASH 为 1,441,280。ARCH／FLASH 实际宏步为 258／103，
方法与 AMR 覆盖共同带来约 3.01 倍单元宏步工作量。Davis 的整程成本比 2.61
已经小于这个粗略工作量比，但单元宏步内部还包含不同的热闭合和分裂求值，
不能将它解释为等计算量、等误差或单算子效率相同。

ARCH 的当前守恒正性约束、两次热耦合燃烧和完整面 EOS 仍保留。FLASH 本组
使用不同的水动限步定义、调用内固定温度 burner 和关闭面 EOS 的参考路线。
前述编译优化只能减少执行开销；剩余成本需要继续区分 EOS 求值、ODE 与方法
工作量，不能仅靠开启 fast-math 或删掉一个半步签收。本文没有证明剩余成本均
不可优化，也没有完成两个反应推进方案的共同科学误差预算。后续 RZ、用户 BC
和长时阶段不会自动替当前未达项消项。

## 成本、精度与对比：本轮收尾判断

用户在本轮最终收尾时明确调整了任务边界：先完成当前实现、验证、记录与推送；
不再为了统一跨代码倍数继续改数值方法。原两倍目标的未达记录保留，以下讨论不授权
新的实现，也不把成本归一化当作原目标已经通过。

**目前证据支持接受这轮共享数学与执行组织的方向。** 默认模型保持原轨迹，两个燃烧
半步和必要 EOS 查询没有省略；相同状态复用、共享 RHS／Jacobian、批量执行及统一
面遍历都有明确的数据依赖边界。最初“普遍存在数量级实现差距”的判断已不适用于
当前表格。但这些短程证据不能证明实现最优，也不能证明 ARCH 比 FLASH 更准确。
历史约 35–40 倍记录还混有不同线程／MPI 配置和旧物理设置，不能与当前 3.49 倍直接
相除，宣传为严格控制下的整体加速倍数；正式改善应沿同输入清单逐轮比较。

### 一、总时间、工作量与每次求值不能混为一谈

定义累计工作量 `W = sum_n N_leaf(n)`，它统计活跃叶单元宏步，不是分配块数，
也不等于 EOS 查询、反应子步或 Poisson 迭代次数。当前细网格有：

| 指标 | ARCH 默认／FLASH | ARCH Davis／FLASH |
| --- | ---: | ---: |
| 完整进程墙钟 | 3.493 | 2.610 |
| 叶单元宏步 | 3.010 | 3.010 |
| 每叶单元宏步的摊销整程时间 | 1.161 | 0.867 |

工作量比还可拆为 `3.010 = 2.505 × 1.202`：宏步多约 150%，平均活跃单元多约 20%。
因此主要差别不是 AMR 平均覆盖多了三倍。相同 `regrid_interval=2` 在不同宏步长度下，
也对应不同的物理时间频率。与此同时，单元宏步内部的 RK、热力学和燃烧求值并不
等价，初始化／输出也摊在分子里。1.161 或 0.867 只能用于成本诊断，不能宣传为
等价内核只慢 16% 或已经比 FLASH 快 13%。

FLASH 官方说明 `EOSforRiemann=false` 使用插值近似的绝热指数，开启后才根据界面态
进行 EOS 求值。这是显式的方法选择，不能称为没有计算物理；ARCH 当前保留完整面
EOS，其成本是否值得应由目标观测量的误差判断。[FLASH 水动文档](https://flash.rochester.edu/site/flashcode/user_support/flash_ug_devel/node105.html)
本机 4.8 源码的 `HydroMain/unsplit/Config` 与 `hy_uhd_getFaceFlux.F90` 也已核对。

同样，ARCH 的热耦合反应系统与这份 FLASH 配置的调用内固定温度推进，不能仅靠
相同 CFL 和最细网格宽度就视为同精度。纯 Sod 接近参考，说明不存在所有模块统一
慢几十倍的现象；它不能单独替燃烧、扩散或引力作精度及效率证明。语言也未改变，
当前改善来自可识别的实现与工作组织，不能为 C++／Fortran 指派一个天然速度倍率。

### 二、继续追固定时间比需要多大的变化

按同一个原 FLASH 中位数 9.2614 s 计算：

| 目标 | ARCH 时间上限 s | 默认方案还需减少 | Davis 方案还需减少 |
| --- | ---: | ---: | ---: |
| 2 倍 FLASH | 18.523 | 42.7% | 23.4% |
| 1.5 倍 FLASH | 13.892 | 57.1% | 42.5% |

在仍承担 3.010 倍单元宏步量的前提下，达到 1.5 倍整程意味着摊销单位成本必须
约为 FLASH 的 0.498。这已是额外研究目标，不能当作几项编译参数应当自然补齐的
差额。严格 O3／LTO 的已测几百分点收益与这一尺度并不相当。

### 三、精度结论分四层

| 层次 | 当前证据 | 尚不能由此推出 |
| --- | --- | --- |
| 实现等价 | 默认成本模型的历史检查点逐位一致；其他受测路径按原预算核对 | 任意输入、任意并发都逐位一致 |
| 方法变体 | 完整 EOS＋Davis 的四个短程 Cellular 在事前预算内；三个面 EOS 近似被否决 | Davis 与 Roe–Glaister 在一般问题中等价 |
| 跨代码科学精度 | 同物理终点、输入及工作量已记录，Sod／Jeans 有已有解析检查 | 两种反应耦合达到共同误差要求，或更严格求值必然更划算 |
| 长期科学适用性 | 现有多物理、AMR 与重启短验证 | 点火时刻、爆轰长期结构、总能漂移和低重复状态中的长期可靠性 |

下一层更合适的对比是 `C(epsilon) = min T(theta), subject to E(theta) <= epsilon`。
这里的 `theta` 只能在预先允许的网格、时间步和容差集合中选择；科学误差目标须先定，
不按已经看到的两代码偏差倒推。对 Cellular，可比较前沿速度／位置、反应区宽度、
累计放热、主要核素和守恒；独立精细参考与收敛检查用于分离空间、时间和模型误差。
不必展开全参数搜索，少量分辨率和时间步序列即可先形成可解释的误差—成本关系。
这属于后续研究设计，本轮没有新增运行或宣称已经取得该曲线。

### 四、仍值得讨论的优化，按问题性质分开

| 方向 | 可能减少的成本 | 实施前必须回答的问题 |
| --- | --- | --- |
| 有证据的执行冗余与低命中成本 | 重复 EOS／网络查询、工作区和任务组织 | 用最终热点而非旧版百分比；在状态丰富、复用率低的场中记录查找成本与未命中代价。现有三维耦合变慢的原因尚未隔离。 |
| 更紧致的稳定性限步 | 宏步和所有随步执行的阶段数量 | 从当前面通量限制、几何与 RK 组合重新证明正性／稳定性，不能直接删除 CFL 的 1/2；验证近真空、强激波和源项耦合。 |
| AMR 指标与重网格时机 | 网格管理和不必要的空间更新 | 对齐物理分辨需求、误差与前沿覆盖；研究按物理变化触发，不直接照抄 FLASH 阈值或减少细化。 |
| 反应—输运耦合方法 | 分裂误差及达到目标误差需要的步数 | 保留当前 Strang 基线；比较替代耦合的稳定性、总能、刚性与 AMR／引力时序，不能只数燃烧函数调用次数。 |
| EOS 反演的有效域与根分支 | 在合法根上减少重复反解 | 先处理 Coulomb 保护附近的根选择语义，再研究热启动；小残差不保证选中同一物理解。 |
| GPU 设备驻留与细粒度调度 | 启动、同步、小归约及跨阶段组织 | 保留同一数学与残差合同，报告绝对时间和规模变化；更强 FP64 不会自动消除串行依赖。 |

替代耦合并非“改成一次燃烧”即可：例如 Castro 同时保留 Strang 与 SDC 类方法，
SDC 通过迭代使反应看到输运源项，可能减少分裂误差，也增加每步工作。它提供了
研究方向，不能据此保证 ARCH 会更快或可直接复用其 AMR 组合。[Castro 推进流程](https://amrex-astro.github.io/Castro/docs/FlowChart.html)

上述表格均为讨论。本轮不会据此实现新时间推进、改变 AMR 判据、加入近似 EOS，
也不为碰巧快的算例添加特殊分支。优先级应由目标科学任务的误差和计算预算确定。

### 五、当前结果应如何使用

共享数学与执行优化可以作为本轮可审查成果收尾；多数 CPU 代表点已处于参考相近
量级，细网格仍有明确的绝对等待成本。原两倍线未全达的事实、三维 CPU 回退，以及
GPU 各点的实际正负收益都保留。短性能验收支持这些受测能力的交付，不替代长期
科研范围的认证，也不证明 FLASH 或 ARCH 是另一方的普遍速度／精度上限。
