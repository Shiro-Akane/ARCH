# 执行成本与科学验收记录

## 1. 记录范围

本记录汇总了执行优化的科学验收结果及 CPU/CUDA 整程执行成本，详细输入与重复采样数据保存在处理后的记录中。相关结论仅覆盖此处列出的软件配置、硬件环境与计算样本，不延伸为跨平台的普适加速结论。

## 2. 冻结的方法与物理

被测基线为 d45ea2956（分支 codex/o8-boundaries）。交付中保留了四项源码优化：Helm 组合前缀与压力-声学同项复用、主机多重网格调度、原始十进制表的流式读取器，以及不可变几何描述符提前。物理与数值设定保持不变：CFL 条件、AMR 判据、完整状态方程、原通量计算与默认 Roe 波速策略，以及 Strang 两半分裂均沿用原实现；单位制保持 CGS，所有旧的科学阈值与容差维持原值。数学内核与物理公式在 CPU 与 CUDA 路径间共享，CUDA 侧复用同一套实现。改动收益均以本轮同口径计时为准，不引用一次性基线对比。

## 3. 测量口径

两个应用使用相同的 8 个物理核心（0、2、4、6、8、10、12、14）：ARCH CPU 运行 OpenMP 8 线程，FLASH 运行 MPI 8 进程；硬件环境为 i7-10700、7.7 GiB RAM。ARCH CPU 采用 GCC 13.3 Release、严格 FP64、O3、native、LTO 以及 `-fno-fast-math -fno-math-errno -ffp-contract=off`。FLASH 使用既有的 4.8 参考执行物，其本地构建文件记录为 O2 与双精度设置；两款软件的编译选项并不相同。计时均覆盖完整进程（含初始化与输出），每个算例进行三次交替采样并核对端点。

表中所列时间为整任务墙钟时间，覆盖相同 CFL、AMR 及分辨率配置下达到相同物理终点的计算；每个模型的实际物理终点见汇总。此外，2D/3D 四模块 5 步能力检查仅用于功能验证，不能用于本表的性能判定。同一物理任务也不等于相同误差，等误差成本需要独立收敛验证；历史比值只能作敏感性参考。

## 7. 保留与撤回的实现

保留项见第 2 节。撤回或未集成的实现及原因如下：负 PATCH FLUX 复用在台账核查后予以撤回；新的组分工作向量在三轮交替测量中收益约为 0%（Sod 与 noburn 算例），在 fine 算例中仅为 0.59% 且区间重叠，故予以撤回；临时原子操作已移除；BD 重试标志未集成（fine 算例实测 618041 次 ODE 调用/装配、0 次被拒宏观步、4944328 次中点调用），生产源码保留原 BD 状态。

审计更正说明：朴素的并行均值预扫会在方向 1/2 上产生数据竞争；滚动组分提案仅有方向 0 满足读取顺序；二分循环原本已具备条件提前退出机制。相关记录已由主智能体更正并复核，这些未实现的提案仅作为讨论记录保留。

## 8. 科学验收与隔离检查

- 单元测试 61/61 通过，耗时 46.85 s。
- 表读取器：2,283,561 个十进制字段与原提取器逐位相等；符号零、下溢、词法边界、垃圾输入与 IO 故障在既有 helm_components 中覆盖。
- 缓存：1120 个严格状态变体/碰撞/查询顺序/属主，旧 Timmes、热力学与求根测试容差不变。
- 公开算例：21 个 CPU 终态检查点具有相同物理时间与 AMR 网格，零修复，其中 20 个逐位相同；其余 fine 重复的最大缩放 Linf 为 2.2184807207102536e-18。
- 耦合算例：2D/3D 四个模块、混合 AMR、5 步；旧固定预算通过，最大检查点误差 2D 为 6.215695995036236e-17、3D 为 0；燃烧、扩散、引力与加密均处于活动状态，零修复。该结论不覆盖长时间演化与解析 SNIa 精度。
- 存储隔离：scratch 与 no-scratch 的三次采样比值约为 1.0（0.994–1.000），18 项科学检查通过。比较结果与隔离样本见 [summary.json](summary.json)。

## 9. 数值方法差异（讨论项）

此前验证的 FLASH 夹具采用定温燃烧并提供可选的面 EOS 旁路；ARCH 则保留了热力学 ODE 组分与能量链式法则、完整面 EOS、正定性 CFL 以及两次 Strang 分裂。本轮细网格计算中，ARCH 仍为 258 步、FLASH 为 103 步；ARCH 水动阶段中位用时 12.17 s，两次燃烧半步合计约 9.01 s。叶单元推进比 3.01 属历史证据，本轮未重新计数。阶段记录说明了剩余热点；但 FLASH 的阶段统计为 MPI 各进程的最大/最小/均值，不能直接对应拼装为 ARCH 的墙钟分解。当前细网格耗时若要进入两倍线，还需要减少约 7.72 s（30.2%），尚无已验证且保持原数值方法的方案达到这一目标；这也不构成理论下界证明。数值方法与精度-成本收敛性、长时间运行表现仍作为讨论项，须在独立误差预算下另行评估。

## 10. CUDA 与线程配置

当前 CUDA 全量 125/125（235.58 s）、42 条引力验收记录，以及 2D/3D 四模块混合 AMR 五步场对照通过原预算。两组耦合终态最大归一场差为 2.45e-12／1.76e-12，均零修复；三维诊断整程为 CPU 39.10 s、CUDA 43.66 s，仍有负收益，不能将周期算例的正收益扩展到全部组合。

正式整程测量使用同一 GCC12/CUDA12.3 执行物，CPU 和 CUDA 均绑定同一八个物理核，CPU 8 线程、CUDA Host 1 线程；262,144 单元推进至物理 `t=0.02 s`，15 个接受步，各三次交替重复。CPU 中位 24.888 s（23.401–25.538），CUDA 18.606 s（18.604–19.155），同执行物收益 **1.338×**。场差保持 `rtol=2e-11, atol=2e-13`，守恒／零修复检查通过。1／4 线程预热更慢，另测 16 逻辑线程三次中位 31.959 s，也更慢。

本轮纯 CPU GCC13、物理核绑定的另一组中位 23.357 s 更快；用它作保守平台分母，CUDA 收益为 **1.255×**。该口径含不同编译器与采样窗口，需与同执行物比值分别解释。最初未绑核的 1.450× 批次全部保留，但不作为最终标题数字。

历史 CPU 时间出现差异后，补测了保存基线与当前纯 CPU 的同编译器、同亲和性三次交替对照：基线 24.874 s，当前 23.357 s，终态字段逐位相同。样本范围重叠，未确认本轮引入退化，也不能把中位差写成所有三维模型的固定改善。
